# ObsidianVault

This repository contains an Obsidian knowledge vault with notes, coursework, project material, and reference content.

## Repository layout

- `Obsidian Vault/` — main vault content (Markdown notes and assets)
  - `College/` — semester and subject notes
  - `Courses/` — external course notes and exercises
  - `Placement/` — interview prep and study material
  - `Projects/` — project-related documentation
  - `Images/` — images embedded in notes
- `.obsidian/` — Obsidian workspace settings, plugins, and configuration

## Getting started

1. Install [Obsidian](https://obsidian.md/).
2. Clone this repository.
3. In Obsidian, choose **Open folder as vault**.
4. Select `./Obsidian Vault` (the vault folder inside this repository).

## Notes

- The vault uses Obsidian-specific configuration from the `.obsidian/` directory.
- Some embedded images are stored at the repository root and in `Obsidian Vault/Images/`.
