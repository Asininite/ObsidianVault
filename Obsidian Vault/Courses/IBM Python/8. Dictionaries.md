# Python Dictionaries

## What are Dictionaries?

- Collection of key-value pairs
    
- Defined using curly braces `{}`
    
- Mutable
    
- Unordered collection (conceptually)
    
- Keys must be unique and immutable
    

```python
student = {
    "name": "John",
    "age": 20,
    "grade": "A"
}
```

---

# Dictionary Syntax

```python
dictionary = {
    key1: value1,
    key2: value2
}
```

---

# Accessing Values

```python
student["name"]
```

Returns:

```python
"John"
```

---

# Adding Elements

```python
student["city"] = "Delhi"
```

---

# Modifying Values

```python
student["age"] = 21
```

---

# Deleting Elements

## del

```python
del(student["grade"])
```

---

## pop()

```python
student.pop("age")
```

Removes and returns value.

---

# Dictionary Length

```python
len(student)
```

Returns number of key-value pairs.

---

# Accessing Keys and Values

## keys()

```python
student.keys()
```

---

## values()

```python
student.values()
```

---

## items()

```python
student.items()
```

Returns key-value pairs as tuples.

---

# Membership Operator

## Check Key Existence

```python
"name" in student
```

Returns:

- `True`
    
- `False`
    

---

# get()

Safely access values.

```python
student.get("name")
```

---

## Default Value

```python
student.get("phone", "Not Found")
```

Avoids KeyError.

---

# Nested Dictionaries

```python
students = {
    "student1": {
        "name": "John",
        "age": 20
    }
}
```

## Access Nested Values

```python
students["student1"]["name"]
```

---

# Dictionary Methods

## update()

Adds or modifies elements.

```python
student.update({"age": 25})
```

---

## clear()

Removes all elements.

```python
student.clear()
```

---

## copy()

Creates shallow copy.

```python
new_student = student.copy()
```

---

# Iterating Through Dictionaries

## Loop Through Keys

```python
for key in student:
    print(key)
```

---

## Loop Through Values

```python
for value in student.values():
    print(value)
```

---

## Loop Through Key-Value Pairs

```python
for key, value in student.items():
    print(key, value)
```

---

# Important Notes

- Keys must be immutable:
    
    - Strings
        
    - Numbers
        
    - Tuples
        
- Lists cannot be keys.
    

---

# Dictionary vs List

|Feature|Dictionary|List|
|---|---|---|
|Storage|Key-value pairs|Ordered values|
|Access|By key|By index|
|Syntax|`{}`|`[]`|
|Mutable|Yes|Yes|

---

# Common Examples

## Basic Dictionary

```python
car = {
    "brand": "BMW",
    "year": 2024
}
```

---

## Access Value

```python
car["brand"]
```

---

## Add New Key

```python
car["color"] = "Black"
```

---

## Iterate Dictionary

```python
for key, value in car.items():
    print(key, value)
```
