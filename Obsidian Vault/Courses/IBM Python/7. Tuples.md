# Python Tuples

## What are Tuples?

- Ordered sequence of elements
    
- Defined using parentheses `()`
    
- Can contain multiple data types
    
- Immutable (cannot be changed)
    

```python
t = (1, 2, "hello", 3.5)
```

---

# Creating Tuples

## Single Element Tuple

```python
t = (1,)
```

> Comma is required.

---

## Without Parentheses

```python
t = 1, 2, 3
```

---

# Accessing Elements

## Positive Indexing

```python
t[0]
t[1]
```

---

## Negative Indexing

```python
t[-1]
t[-2]
```

|Index|Meaning|
|---|---|
|`-1`|Last element|
|`-2`|Second last|

---

# Tuple Slicing

```python
t[1:4]
```

Returns elements from index `1` to `3`.

---

## Step / Stride

```python
t[::2]
```

---

# Tuple Length

```python
len(t)
```

---

# Tuple Concatenation

```python
t1 + t2
```

---

# Tuple Repetition

```python
(1, 2) * 3
```

Output:

```python
(1, 2, 1, 2, 1, 2)
```

---

# Immutability

Tuples cannot be modified.

```python
t[0] = 10   # Error
```

- No insertion
    
- No deletion
    
- No replacement
    

---

# Nested Tuples

```python
nt = (1, (2, 3), ("A", "B"))
```

## Access Nested Elements

```python
nt[1][0]
nt[2][1]
```

---

# Tuple Packing

```python
person = ("John", 20, "India")
```

Multiple values packed into one tuple.

---

# Tuple Unpacking

```python
name, age, country = person
```

---

# Membership Operator

```python
"John" in person
```

Returns:

- `True`
    
- `False`
    

---

# Iterating Through Tuples

```python
for item in t:
    print(item)
```

---

# Sorting Tuples

```python
sorted(t)
```

- Returns a new sorted list
    
- Original tuple unchanged
    

---

# Type Conversion

## Tuple to List

```python
list(t)
```

---

## List to Tuple

```python
tuple([1, 2, 3])
```

---

# Important Notes

- Tuples are faster than lists
    
- Used for fixed data
    
- Can be dictionary keys (lists cannot)
    
- Safer because immutable
    

---

# List vs Tuple

|Feature|Tuple|List|
|---|---|---|
|Syntax|`()`|`[]`|
|Mutable|No|Yes|
|Faster|Yes|Slightly slower|
|Memory Usage|Lower|Higher|
|Dictionary Key Allowed|Yes|No|

---

# Common Examples

## Basic Tuple

```python
t = (1, 2, 3)
print(t[1])
```

---

## Nested Tuple

```python
nt = (1, (2, 3))
print(nt[1][0])
```

---

## Tuple Unpacking

```python
a, b, c = (1, 2, 3)
```

---

## Swap Variables Using Tuple

```python
a, b = b, a
```
