# Python Lists 

## Compound Data Types

- Lists and tuples are compound data types in Python.
    
- Both are ordered sequences.
    
- Both support:
    
    - Indexing
        
    - Negative indexing
        
    - Slicing
        
    - Nesting
        

---

# Tuples

## Creating Tuples

```python
ratings = (10, 9, 6, 5, 10)
```

- Defined using parentheses `()`
    
- Can contain multiple data types:
    
    - Strings
        
    - Integers
        
    - Floats
        
    - Other tuples
        

---

## Accessing Elements

```python
ratings[0]   # first element
ratings[1]   # second element
ratings[-1]  # last element
```

### Negative Indexing

|Index|Meaning|
|---|---|
|`-1`|Last element|
|`-2`|Second last element|

---

## Tuple Slicing

```python
ratings[0:3]
```

Returns elements from index `0` to `2`.

```python
ratings[3:5]
```

Returns last two elements.

> End index is exclusive.

---

## Tuple Length

```python
len(ratings)
```

---

## Tuple Concatenation

```python
tuple1 + tuple2
```

---

## Immutability

- Tuples are **immutable**
    
- Cannot be modified after creation
    

```python
ratings[0] = 5   # Error
```

### Variable Referencing

```python
a = ratings
```

- Variables reference the same tuple object.
    
- Since tuples are immutable:
    
    - modification is impossible
        
    - no side effects occur
        

---

## Sorting Tuples

```python
sorted_tuple = sorted(ratings)
```

- `sorted()` returns a **new list**
    
- Original tuple remains unchanged
    

---

## Nested Tuples

```python
nt = (1, 2, ("A", "B"))
```

### Access Nested Elements

```python
nt[2][1]
```

# Aliasing
The correct answer is:

```python
player_attributes = default_attributes[:]
```

because `[:]` creates a **copy (clone)** of the list.

---

# Why Your Answer Was Wrong

You selected:

```python
player_attributes = default_attributes
```

This does **NOT** create a new list.

It only creates another variable pointing to the SAME list.

This is called **aliasing**.

---

# Visual Understanding

## Your Answer

```python
default_attributes = ["warrior", 100, 50, 10]
player_attributes = default_attributes
```

Memory view:

```text
default_attributes ─┐
                    ├──> ["warrior", 100, 50, 10]
player_attributes ──┘
```

Both variables point to the SAME list.

---

# Problem

If you modify one:

```python
player_attributes[1] = 999
```

Then:

```python
print(default_attributes)
```

Output:

```python
["warrior", 999, 50, 10]
```

Original list also changes.

That is BAD if you want independent copies.

---

# Correct Method: Cloning

```python
player_attributes = default_attributes[:]
```

This creates a NEW list.

Memory view:

```text
default_attributes ──> ["warrior", 100, 50, 10]

player_attributes ──> ["warrior", 100, 50, 10]
```

Now they are separate objects.

---

# Proof

```python
default_attributes = ["warrior", 100, 50, 10]

player_attributes = default_attributes[:]

player_attributes[1] = 999

print(default_attributes)
print(player_attributes)
```

Output:

```python
['warrior', 100, 50, 10]
['warrior', 999, 50, 10]
```

Original remains unchanged.

---

# Why Other Options Are Wrong

## Option 1

```python
player_attributes.copy(default_attributes)
```

Wrong syntax.

Correct syntax would be:

```python
player_attributes = default_attributes.copy()
```

---

## Option 4

```python
player_attributes = [default_attributes]
```

Creates a nested list.

Result:

```python
[
   ["warrior", 100, 50, 10]
]
```

Not a clone.

# Important Interview / Exam Concept

|Code|Meaning|
|---|---|
|`b = a`|Alias (same list)|
|`b = a[:]`|Clone / copy|
|`b = a.copy()`|Clone / copy|

---

# Very Important Rule

## Mutable Objects (Lists)

Assignment copies the **reference**, not the actual object.

```python
b = a
```

Both variables share the same memory object.

---

# Simple Intuition

## `=`

```text
"Use the same notebook"
```

## `[:]`

```text
"Photocopy the notebook"
```
```python
a = [1, 2, 3]
b = a
```

- Both variables reference the same list object.
    

```python
a[0] = 100
```

Now:

```python
b == [100, 2, 3]
```

# Key Difference: Lists vs Tuples

|Feature|Tuple|List|
|---|---|---|
|Syntax|`()`|`[]`|
|Mutable|No|Yes|
|Can be modified|No|Yes|
|Faster|Usually|Slightly slower|
|Common Use|Fixed data|Dynamic data|

# Important append() vs extend()

|Method|Behavior|
|---|---|
|`append(x)`|Adds entire object as one element|
|`extend(x)`|Adds each element individually|

Example:

```python
A.append([1, 2])
```

Result:

```python
[existing, [1, 2]]
```

```python
A.extend([1, 2])
```

Result:

```python
[existing, 1, 2]
```
