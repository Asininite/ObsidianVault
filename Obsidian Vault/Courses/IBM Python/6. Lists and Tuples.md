# Python Lists and Tuples

## Compound Data Types

- Lists and tuples are compound data types in Python.
    
- Both are ordered sequences.
    
- Both support:
    
    - Indexing
        
    - Negative indexing
        
    - Slicing
        
    - Nesting
        

---

# Tuples

## Creating Tuples

```python
ratings = (10, 9, 6, 5, 10)
```

- Defined using parentheses `()`
    
- Can contain multiple data types:
    
    - Strings
        
    - Integers
        
    - Floats
        
    - Other tuples
        

---

## Accessing Elements

```python
ratings[0]   # first element
ratings[1]   # second element
ratings[-1]  # last element
```

### Negative Indexing

|Index|Element|
|---|---|
|`-1`|last|
|`-2`|second last|

---

## Tuple Slicing

```python
ratings[0:3]
```

Returns elements from index `0` to `2`.

```python
ratings[3:5]
```

Returns last two elements.

> End index is exclusive.

---

## Tuple Length

```python
len(ratings)
```

---

## Tuple Concatenation

```python
tuple1 + tuple2
```

---

## Immutability

- Tuples are **immutable**
    
- Elements cannot be changed after creation
    

```python
ratings[0] = 5   # Error
```

### Important Concept

Variables reference the same tuple object.

```python
a = ratings
```

Since tuples are immutable:

- modifying is impossible
    
- no side effects occur


---

## Sorting Tuples

```python
sorted_tuple = sorted(ratings)
```

- `sorted()` returns a **new list**
    
- Original tuple remains unchanged


---

## Nested Tuples

```python
nt = (1, 2, ("A", "B"))
```

### Accessing Nested Elements

```python
nt[2][1]
```

---

# Lists

## Creating Lists

```python
L = ["Michael Jackson", 10, 1.2]
```

- Defined using square brackets `[]`
    
- Can contain:
    
    - Strings
        
    - Numbers
        
    - Other lists
        
    - Tuples
        

---

## Accessing Elements

```python
L[0]
L[-1]
```

---

## List Slicing

```python
L[1:3]
```

---

## List Concatenation

```python
L1 + L2
```

---

# List Mutability

Lists are **mutable**.

```python
L[0] = "Hard Rock"
```

---

## extend()

Adds multiple elements individually.

```python
L.extend(["Pop", 10])
```

### Result

```python
["Hard Rock", 10, 1.2, "Pop", 10]
```

---

## append()

Adds one single element.

```python
L.append(["Pop", 10])
```

### Result

```python
["Hard Rock", 10, 1.2, ["Pop", 10]]
```

---

## Deleting Elements

```python
del(L[0])
```

---

# String to List Conversion

## split()

### Split by Space

```python
"A B C".split()
```

### Split by Delimiter

```python
"A,B,C".split(",")
```

---

# Aliasing

```python
a = [1, 2, 3]
b = a
```

- Both variables reference the same list.
    

```python
a[0] = 100
```

Now:

```python
b == [100, 2, 3]
```

---

# Cloning Lists

```python
b = a[:]
```

Creates a copy.

Changes to `a` will not affect `b`.

---

# Key Difference: Lists vs Tuples

| Feature         | Tuple      | List            |
| --------------- | ---------- | --------------- |
| Syntax          | `()`       | `[]`            |
| Mutable         | No         | Yes             |
| Can be modified | No         | Yes             |
| Faster          | Usually    | Slightly slower |
| Common Use      | Fixed data | Dynamic data    |

---

# Important Methods & Functions

|Function/Method|Purpose|
|---|---|
|`len()`|Length|
|`sorted()`|Returns sorted list|
|`append()`|Add single element|
|`extend()`|Add multiple elements|
|`split()`|Convert string to list|
|`del`|Remove element|

---

# Common Examples

## Tuple Example

```python
t = (1, 2, 3)
print(t[1])
```

## List Example

```python
L = [1, 2, 3]
L.append(4)
print(L)
```

## Nested Access

```python
nt = (1, (2, 3))
print(nt[1][0])
```
