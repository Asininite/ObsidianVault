# Python Functions

## What are Functions?

Functions are reusable blocks of code.

Used to:

- avoid repetition
    
- organize programs
    
- simplify complex tasks
    

---

# Creating Functions

## Syntax

```python
def function_name():
    statements
```

---

## Basic Example

```python
def greet():
    print("Hello")
```

---

# Calling Functions

Function executes only when called.

```python
greet()
```

Output:

```python
Hello
```

---

# Function Parameters

Parameters are inputs to functions.

```python
def greet(name):
    print("Hello", name)
```

---

## Example

```python
greet("John")
```

Output:

```python
Hello John
```

---

# Multiple Parameters

```python
def add(a, b):
    print(a + b)
```

---

# return Statement

`return` sends value back from function.

```python
def add(a, b):
    return a + b
```

---

## Example

```python
result = add(2, 3)

print(result)
```

Output:

```python
5
```

---

# Difference Between print() and return()

## print()

Displays value only.

```python
def add(a, b):
    print(a + b)
```

---

## return()

Returns value for later use.

```python
def add(a, b):
    return a + b
```

---

# Functions Without Return

If no `return`:

```python
def test():
    print("Hello")
```

Python automatically returns:

```python
None
```

---

# Default Parameters

```python
def greet(name="Guest"):
    print("Hello", name)
```

---

## Example

```python
greet()
```

Output:

```python
Hello Guest
```

---

# Variable Scope

## Local Variable

Exists only inside function.

```python
def test():
    x = 10
```

---

## Global Variable

Defined outside function.

```python
x = 100

def show():
    print(x)
```

# Functions Returning Multiple Values

```python
def calc(a, b):
    return a+b, a-b
```

---

## Example

```python
x, y = calc(10, 5)
```

---

# Passing Lists to Functions

```python
def print_list(L):
    for item in L:
        print(item)
```

---

# Modifying Lists Inside Functions

Lists are mutable.

```python
def change(L):
    L[0] = "Changed"
```

Changes affect original list.

---

# Important Concept: Scope

```python
x = 10

def test():
    x = 5
    print(x)

test()
print(x)
```

Output:

```python
5
10
```

Local variable does not affect global variable.

---

# Recursive Functions

Function calling itself.

```python
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n-1)
```

---

# Lambda Functions

Small anonymous functions.

```python
square = lambda x: x*x
```

---

## Example

```python
square(5)
```

Output:

```python
25
```

---

# Important Notes

- Functions improve code reuse
    
- Parameters receive inputs
    
- `return` gives outputs
    
- Variables inside functions are usually local
    

---

# Common Function Patterns

## Sum Function

```python
def add(a, b):
    return a + b
```

---

## Check Even Number

```python
def is_even(n):
    return n % 2 == 0
```

---

## Find Maximum

```python
def maximum(a, b):
    if a > b:
        return a
    return b
```

|Term|Meaning|
|---|---|

|return|Sends value back|
|Local Variable|Exists inside function|
|Global Variable|Exists outside function|

# Most Important Intuition

A function is like a machine:

```text
input → processing → output
```

Example:

```python
def square(x):
    return x*x
```

Input:

```python
4
```

Processing:

```python
4 * 4
```

Output:

```python
16
```
