# Python Loops

Loops are used to repeat code multiple times.

Python has:

- `for` loops
    
- `while` loops
    

---

# for Loop

Used for iterating through sequences:

- lists
    
- tuples
    
- strings
    
- sets
    
- dictionaries
    

---

## Basic Syntax

```python
for variable in sequence:
    statements
```

---

## Example

```python
fruits = ["apple", "banana", "orange"]

for fruit in fruits:
    print(fruit)
```

Output:

```python
apple
banana
orange
```

---

# How for Loop Works

Python takes elements one by one:

|Iteration|fruit|
|---|---|
|1|apple|
|2|banana|
|3|orange|

---

# Looping Through Strings

```python
for ch in "HELLO":
    print(ch)
```

---

# range()

Used to generate numbers.

---

## range(stop)

```python
range(5)
```

Generates:

```python
0, 1, 2, 3, 4
```

---

## Example

```python
for i in range(5):
    print(i)
```

Output:

```python
0
1
2
3
4
```

---

# range(start, stop)

```python
range(2, 6)
```

Generates:

```python
2, 3, 4, 5
```

---

# range(start, stop, step)

```python
range(0, 10, 2)
```

Generates:

```python
0, 2, 4, 6, 8
```

---

# enumerate()

Used when you need:

- index
    
- value
    

together.

```python
fruits = ["apple", "banana"]

for i, fruit in enumerate(fruits):
    print(i, fruit)
```

Output:

```python
0 apple
1 banana
```

---

# Looping Through Dictionaries

## Keys

```python
student = {
    "name": "John",
    "age": 20
}

for key in student:
    print(key)
```

---

## Values

```python
for value in student.values():
    print(value)
```

---

## Key-Value Pairs

```python
for key, value in student.items():
    print(key, value)
```

---

# while Loop

Repeats while condition is `True`.

---

## Syntax

```python
while condition:
    statements
```

---

## Example

```python
count = 0

while count < 5:
    print(count)
    count += 1
```

Output:

```python
0
1
2
3
4
```

---

# Infinite Loop

```python
while True:
    print("Hello")
```

Runs forever unless stopped.

---

# break

Stops loop immediately.

```python
for i in range(10):
    if i == 5:
        break
    print(i)
```

Output:

```python
0
1
2
3
4
```

---

# continue

Skips current iteration.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

Output:

```python
0
1
3
4
```

---

# pass

Placeholder statement.

```python
for i in range(5):
    pass
```

Does nothing.

---

# Nested Loops

Loop inside another loop.

```python
for i in range(3):
    for j in range(2):
        print(i, j)
```

Output:

```python
0 0
0 1
1 0
1 1
2 0
2 1
```

---

# Common Patterns

## Sum of Numbers

```python
total = 0

for i in range(5):
    total += i

print(total)
```

---

## Find Element

```python
nums = [1, 2, 3]

for n in nums:
    if n == 2:
        print("Found")
```

---

## Count Characters

```python
count = 0

for ch in "HELLO":
    count += 1
```

---

# Important Notes

- `for` loop → used when iterations are known
    
- `while` loop → used when condition controls repetition
    
- `range()` stop value is excluded
    
- `enumerate()` gives `(index, value)` pairs
    

---

# Most Important Loop Concepts

| Concept       | Meaning                     |
| ------------- | --------------------------- |
| `for`         | Iterate over sequence       |
| `while`       | Repeat while condition true |
| `range()`     | Generate numbers            |
| `break`       | Exit loop                   |
| `continue`    | Skip iteration              |
| `enumerate()` | Get index + value           |
