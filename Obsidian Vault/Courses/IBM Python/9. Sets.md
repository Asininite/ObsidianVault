# Python Sets

## What are Sets?

- Unordered collection of unique elements
    
- Defined using curly braces `{}` or `set()`
    
- Mutable
    
- Automatically removes duplicates
    

```python
S = {1, 2, 3, 3}
```

Result:

```python
{1, 2, 3}
```

---

# Creating Sets

## Using Curly Braces

```python
A = {"apple", "banana", "orange"}
```

---

## Using set()

```python
A = set([1, 2, 3])
```

---

## Empty Set

```python
A = set()
```

> `{}` creates an empty dictionary, not a set.

---

# Important Properties

- No duplicate elements
    
- No indexing
    
- Unordered
    
- Mutable
    
- Elements must be immutable
    

---

# Adding Elements

## add()

```python
A.add("grape")
```

---

# Removing Elements

## remove()

```python
A.remove("apple")
```

- Raises error if element not found.
    

---

## discard()

```python
A.discard("apple")
```

- No error if element missing.
    

---

## pop()

```python
A.pop()
```

- Removes random element.
    

---

## clear()

```python
A.clear()
```

Removes all elements.

---

# Set Operations

## Union

Combines all unique elements.

```python
A.union(B)
```

or

```python
A | B
```

---

## Intersection

Common elements only.

```python
A.intersection(B)
```

or

```python
A & B
```

---

## Difference

Elements in first set but not second.

```python
A.difference(B)
```

or

```python
A - B
```

---

## Symmetric Difference

Elements not common to both sets.

```python
A.symmetric_difference(B)
```

or

```python
A ^ B
```

---

# Membership Operator

```python
"apple" in A
```

Returns:

- `True`
    
- `False`
    

---

# Set Length

# Type Conversion

## List to Set

```python
set([1, 2, 2, 3])
```

---

## Set to List

```python

```

---

# Frozen Sets

Immutable version of set.

```python
fs = frozenset([1, 2, 3])
```

- Cannot be modified
    
- Can be dictionary keys
    

---

# Important Notes

- Sets remove duplicates automatically
    
- Fast membership checking
    
- Useful for mathematical operations
    
- No indexing or slicing
    

---

# Set vs List

|Feature|Set|List|
|---|---|---|
|Ordered|No|Yes|
|Duplicates Allowed|No|Yes|
|Mutable|Yes|Yes|
|Indexing|No|Yes|
|Syntax|`{}`|`[]`|
