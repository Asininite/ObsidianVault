# Django Admin Site: Setup and Customization

## Overview

Django provides a powerful, built-in admin interface out-of-the-box. It allows site managers and developers to manage application content (Create, Read, Update, Delete) without writing custom views or using the database shell, effectively separating content publishers from end-users.

## 1. Initial Setup

To access the admin site, you first need an administrative user account.

- **Command:** Run `python manage.py createsuperuser` in your terminal.
    
- **Action:** Provide a username, email, and password when prompted.
    
- **Access:** Start the server (`python manage.py runserver`) and navigate to the `/admin` URL to log in.
    

## 2. Registering Models (Basic)

By default, models don't appear in the admin site. You must register them in your app's `admin.py` file.

- Django automatically generates appropriate UI widgets based on the model's field types (e.g., checkboxes for Booleans, numeric inputs for Integers).
    

**Example (`admin.py`):**

```
from django.contrib import admin
from .models import Course, Instructor

admin.site.register(Course)
admin.site.register(Instructor)
```

## 3. Customizing the Admin Interface

You can customize how models are displayed and edited by creating a `ModelAdmin` class and passing it as a second argument to the `register` method.

### A. Selecting and Ordering Fields

You can restrict which fields are editable and set their specific order on the detail page using the `fields` attribute.

```
class CourseAdmin(admin.ModelAdmin):
    # Only these fields will show on the form, in this exact order
    fields = ['pub_date', 'name', 'description']

admin.site.register(Course, CourseAdmin)
```

### B. Inline Models (Parent-Child Relationships)

Instead of adding related objects (like Lessons belonging to a Course) one by one on separate pages, you can add them directly to the parent model's form using `admin.StackedInline` or `admin.TabularInline`.

```
# 1. Define the Inline class
class LessonInline(admin.StackedInline):
    model = Lesson
    extra = 5  # Shows 5 empty form slots by default

# 2. Add to the parent's ModelAdmin
class CourseAdmin(admin.ModelAdmin):
    fields = ['pub_date', 'name', 'description']
    inlines = [LessonInline] # Adds Lesson forms inside the Course form

admin.site.register(Course, CourseAdmin)
```

### C. Customizing the List View Columns

When viewing multiple records in a table format, Django only shows the object's string representation by default. Use `list_display` to specify exactly which columns should appear.

```
class CourseAdmin(admin.ModelAdmin):
    # Shows specific columns in the main table view
    list_display = ('name', 'pub_date')
```

### D. Adding Search and Filters

For long lists of records, you can easily add search bars and filter sidebars.

```
class CourseAdmin(admin.ModelAdmin):
    list_display = ('name', 'pub_date')
    # Adds a search bar that searches the specified fields
    search_fields = ['name', 'description']
    # Adds a sidebar filter menu for the specified fields
    list_filter = ['pub_date']
```
