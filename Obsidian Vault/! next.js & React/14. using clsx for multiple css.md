There may be cases where you may need to conditionally style an element based on state or some other condition.

[`clsx`](https://www.npmjs.com/package/clsx) is a library that lets you toggle class names easily. We recommend taking a look at [documentation](https://github.com/lukeed/clsx) for more details, but here's the basic usage:

- Suppose that you want to create an `InvoiceStatus` component which accepts `status`. The status can be `'pending'` or `'paid'`.
- If it's `'paid'`, you want the color to be green. If it's `'pending'`, you want the color to be gray.

You can use `clsx` to conditionally apply the classes, like this:

`status.tsx`
```tsx
import clsx from 'clsx';
export default function ButtonStatus({status}: {status: string}) {
    return (
        <span
            className={clsx(
                'inline-flex items-center rounded-full px-2 py-1 text-sm',
                {
                    'bg-gray-100 text-gray-100': status == 'pending',
                    'bg-green-500 text-white': status == 'paid',
                },
            )}
    > {status} </span>)
}
```

`page.tsx`
```tsx
import ButtonStatus from '@/app/ui/status';

export default function Page(){
	return (
		<main className="flex">
			<ButtonStatus title="paid" />
		</main>
	);
}
```
