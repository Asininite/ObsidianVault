```html
<html>
    <body>
        <div id="app">
            <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
            <!-- Babel Script for Compiling JSX-->
            <script src="https://unpkg.com/react@18/umd/react.development.js"></script>
            <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
            <!-- add react to the web site-->
            <script type="text/jsx">    
                const app = document.getElementById('app');
                function Header() {
                    return <h1> Develop. Publish. Ship.</h1>;
                }
                
                function SayHi(){
                    return (
	                    <h2> Hi All!. </h2>
	                    <h3> How are you guys doing? </h3>
	                );
                }
                
                function Homepage(){
                    return(
                        <div>
                            <Header />
                            <SayHi />
                        </div>
                    );
                }
                const root = ReactDOM.createRoot(app);
                root.render(<Homepage />);
            </script>
        </div>
    </body>
</html>
```

- here I added react to the web page by importing it and added **Babel** to compile **JSX to JS**
- in the script tag, you create a app const for the main div
- then create a **react** function, which must always be **Capital Case** to distinguish from HTML
- call react functions like **html elements**, and you can nest functions

- create the root and then use it to render elements according to the component tree, and we only need to render Homepage() for all the other elements to get rendered
