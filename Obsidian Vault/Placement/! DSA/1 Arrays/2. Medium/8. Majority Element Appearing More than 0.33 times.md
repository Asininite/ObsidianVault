Given an **integer** array **nums** of size **_n_**. Return **all** elements which **appear more than** **n/3** times in the array. The output can be returned in **any** order.

Example 1

**Input**: nums = [1, 2, 1, 1, 3, 2]

**Output**: [1]

**Explanation**:

Here, n / 3 = 6 / 3 = 2.

Therefore the elements appearing 3 or more times is : [1]

Example 2

**Input**: nums = [1, 2, 1, 1, 3, 2, 2]

**Output**: [1, 2]

**Explanation**:

Here, n / 3 = 7 / 3 = 2.

Therefore the elements appearing 3 or more times is : [1, 2]




# Optimum

## 🧩 Problem

Find all elements in an array that appear **more than ⌊n/3⌋ times**.

---

## 🧠 Key Observations

1. There can be **at most 2 such elements**
    
    If 3 elements each appear > n/3 → total > n → impossible
    
2. Brute force (count each element) → **O(n²)**  
    Optimized approach → **Boyer–Moore Voting Algorithm (extended)** → **O(n)**

---

# 🎯 Core Intuition (The Most Important Part)

Think in terms of **elimination**:

> Whenever you encounter **3 different elements**, you can cancel them out.

Because:

- None of them can be majority (> n/3)

---

## 🧠 Mental Model

- Majority elements = **strong (frequent)**
- Others = **weak**

When we cancel:

strong vs weak → strong survives

---

# 🔄 Algorithm Overview

We maintain:

el1, cnt1  
el2, cnt2

### Two Phases:

1. **Voting Phase (find candidates)**
2. **Verification Phase (check actual counts)**

---

# 🪜 Phase 1: Voting (Find Candidates)

### Rules:

For each element `num`:

1. If `cnt1 == 0` and `num != el2`  
    → set `el1 = num`, `cnt1 = 1`
2. Else if `cnt2 == 0` and `num != el1`  
    → set `el2 = num`, `cnt2 = 1`
3. Else if `num == el1`  
    → `cnt1++`
4. Else if `num == el2`  
    → `cnt2++`
5. Else  
    → `cnt1--`, `cnt2--` (**elimination step**)

---

## 🔥 What does elimination mean?

If num is different from both el1 and el2:  
    we remove one occurrence of all three

👉 Equivalent to:

(el1, el2, num) → cancel out

---

# 📌 Example Walkthrough

### Input:

[1, 2, 3, 1, 2, 1, 1]

### Step-by-step:

|Element|Action|
|---|---|
|1|el1=1, cnt1=1|
|2|el2=2, cnt2=1|
|3|different → cnt1--, cnt2-- → (0,0)|
|1|el1=1, cnt1=1|
|2|el2=2, cnt2=1|
|1|cnt1=2|
|1|cnt1=3|

---

### After Phase 1:

Candidates:  
el1 = 1  
el2 = 2

---

# ⚠️ Important Truth

After this phase:

cnt1 and cnt2 are NOT real frequencies ❌

They are just leftover counts after cancellations.

---

# 🔄 Phase 2: Verification (Why Reset?)

We reset:

cnt1 = 0;  
cnt2 = 0;

👉 Because previous counts are meaningless.

---

## Now count actual occurrences:

1 → 4 times ✅ (> n/3)  
2 → 2 times ❌

---

## ✅ Final Answer:

[1]

---

# ❗ Why Reset is Necessary

If you don’t reset:

- You use **wrong counts**
- You may return incorrect answers

---

## 🧠 Clean Understanding

### Phase 1:

“Find possible majority elements”

### Phase 2:

“Check if they are actually majority”

---

# 🔑 One-Line Intuition

> Remove groups of 3 different elements → only strong (frequent) elements survive → verify them.

---

# ⚡ Full Logic Summary

1. Track at most 2 candidates
2. Cancel out different elements
3. Survivors = possible answers
4. Recount to confirm
5. Return elements with count > n/3

---

# 🚀 Complexity

- Time: **O(n)**
- Space: **O(1)**

---

# 🧠 Final Mental Picture

Array → cancel weak elements → only strong remain → verify → answer

```cpp
class Solution {
public:
    vector<int> majorityElementTwo(vector<int>& nums) {
        int el1 = INT_MIN;
        int el2 = INT_MIN;
        int cnt1 = 0;
        int cnt2 = 0;
          for(int i = 0; i < nums.size(); i++){
            if(cnt1 == 0 && el2 != nums[i]){
                cnt1 = 1;
                el1 = nums[i];
            } else if (cnt2 == 0 && el1 != nums[i]){
                cnt2 = 1;
                el2 = nums[i];
            } else if (nums[i] == el1){
                cnt1++;
            } else if (nums[i] == el2){
                cnt2++;
            } else {
                cnt1--;
                cnt2--;
            }
        }
  
        cnt1 = 0;
        cnt2 = 0;
  

        for(int i = 0; i < nums.size(); i++){
            if(nums[i] == el1){
                cnt1++;
            }
            if(nums[i] == el2){
                cnt2++;
            }
        }
        int mini = nums.size()/3 + 1;
        vector<int> result;

        if (cnt1 >= mini){
            result.push_back(el1);
        }
        
        if(cnt2 >= mini && el1 != el2){
            result.push_back(el2);
        }
  
        return result;
    }
};
```
