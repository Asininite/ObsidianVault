- Use the Dutch National Flag Algorithm
- initialize `low = 0`, `mid = 0`, `high = last_element_index`
- if `mid` pointer is at a **0**, **swap** with `low` and **increment** both `mid` and `low`
- if `mid` pointer is at a **1**, **increment** `mid`
- if `mid` pointer is at a **2**, **swap** `mid` and `high` and **decrement** `high`

## 🧩 Dutch National Flag Algorithm — Key Idea

We maintain three regions:

```text
[0 ... low-1]     → all 0s  
[low ... mid-1]   → all 1s  
[mid ... high]    → unknown  
[high+1 ... n-1]  → all 2s  
```

We process the array using `mid`.

---

## 🔍 Case: `nums[mid] == 2`

We do:

```cpp
swap(nums[mid], nums[high]);
high--;
```

### ❓ Why NOT increment `mid`?

Because after swapping, the element that comes to position `mid` is **unknown**.

---

## 🎯 Key Insight

When you swap:

```text
nums[mid] ↔ nums[high]
```

- You correctly place `2` at the end
    
- But the new `nums[mid]` (coming from `high`) could be:
    
    - 0 → needs to go left
        
    - 1 → fine
        
    - 2 → needs to go right again
        

👉 So you **must re-check the same index**

---

## 🔄 Visualization

### Example:

```text
nums = [1, 2, 0]
         ↑
        mid
             ↑
            high
```

### Step:

Swap `nums[mid]` and `nums[high]`

```text
[1, 0, 2]
    ↑
   mid
        ↑
       high--
```

Now:

- `nums[mid] = 0` → needs to go to left side
    
- If you had done `mid++`, you would **skip this 0 → wrong result**
    

---

## ⚠️ What Goes Wrong If You Do `mid++`

You might leave elements unprocessed → array not sorted correctly.

---

## ✅ Compare All 3 Cases

|Value|Action|Why|
|---|---|---|
|`0`|swap with `low`, `low++`, `mid++`|left side confirmed|
|`1`|`mid++`|already in correct region|
|`2`|swap with `high`, `high--`|must re-check swapped value|

---

## 🧠 Mental Model

- `mid` moves only when you're **sure** the current element is correctly placed
    
- After swapping with `high`, you're **not sure** → so don't move `mid`
    

---

## 🔑 One-Line Intuition

> When swapping with `high`, you bring in an **unprocessed element**, so you must **check it again**

```cpp
#include <bits/stdc++.h>
using namespace std;
void sortArray(vector<int>& arr, int n) {

    int low = 0, mid = 0, high = n - 1; // 3 pointers

    while (mid <= high) {
        if (arr[mid] == 0) {
            swap(arr[low], arr[mid]);
            low++;
            mid++;
        }
        else if (arr[mid] == 1) {
            mid++;
        }
        else {
            swap(arr[mid], arr[high]);
            high--;
        }
    }
}

int main()
{
    int n = 6;
    vector<int> arr = {0, 2, 1, 2, 0, 1};
    sortArray(arr, n);
    cout << "After sorting:" << endl;
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
    return 0;
}
```
