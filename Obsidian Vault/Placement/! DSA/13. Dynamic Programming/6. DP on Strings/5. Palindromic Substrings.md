## Tabulation
```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size();
        int ans = 0;
        vector<string> real_ans;
        
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        for(int i = 0; i < n; i++){
            dp[i][i] = true;
        }
  
        for (int i = n-1; i >= 0; i--){
            for (int j = i; j < n; j++){
                if(s[i] == s[j] && (j - i + 1 <= 2 || dp[i+1][j-1])){
                    dp[i][j] = true;
                    ans++;
                    real_ans.push_back(s.substr(i, j - i + 1));
               }
            }
        }
        return ans;
    }
};
```

1. The solution is similar to [[4. Longest Palindromic Substring]]
2. We initialize a dp matrix for each possible substring with indices ranging from i to j
3. Then we initialize an i index from the end, j from i to the end and check each substring
4. If the character at `s[i]` and `s[j]` are the same
	   either i and j represent the same character
		   Since each character of the string is its own palindrome (aka 'a') we set that as true
	   or i and j are adjacent in which case they are a palindrome
	   or the substring just outside the current substring 
		   aka i + 1 since i is taken from the end and j - 1 since j is taken from the start 
		   for eg in `ababa` suppose i and j is `1 and 3` then we check the substring `0 and 4` and find that it is a palindrome, hence the inner substring will also be a palindrome
5. increment ans and set the `dp[i][j]` to true
6. return ans
