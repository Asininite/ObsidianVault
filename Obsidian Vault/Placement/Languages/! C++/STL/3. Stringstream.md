Here’s a **quick and simple guide** to `stringstream` and other useful C++ string functions you should know for your test.

---

### ✅ 1️⃣. `stringstream` (from `<sstream>`)

Used to **split strings easily into words or tokens** (like splitting by spaces, commas, etc.).

#### Example:

```cpp
#include <iostream>
#include <sstream>
#include <vector>
using namespace std;

int main() {
    string s = "10 20 30 40";
    stringstream ss(s);

    int num;
    vector<int> numbers;

    while (ss >> num) {
        numbers.push_back(num);
    }

    for (int x : numbers) cout << x << " ";  // Output: 10 20 30 40
}
```

👉 Great for splitting space-separated numbers or words.

---

### ✅ 2️⃣. `find()`

- Finds the position of a substring in a string.
    

```cpp
string s = "hello world";
int pos = s.find("world");  // pos = 6
```

👉 Returns `string::npos` if not found.

---

### ✅ 3️⃣. `substr()`

- Extract a substring from a string.
    

```cpp
string s = "hello world";
string sub = s.substr(0, 5);  // sub = "hello"
```

👉 Parameters: `substr(startIndex, length)`

---

### ✅ 4️⃣. `length()` or `size()`

- Get the length of the string.
    

```cpp
string s = "hello";
int len = s.length();  // len = 5
```

---

### ✅ 5️⃣. `stoi()` and `to_string()`

- Convert string ↔ integer.
    

```cpp
string s = "123";
int num = stoi(s);      // num = 123
string str = to_string(456);  // str = "456"
```

---

### ✅ 6️⃣. `erase()` and `insert()`

- `erase(pos, len)` → Remove part of string.
    

```cpp
string s = "hello world";
s.erase(5, 1);  // s becomes "helloworld" (removed space)
```

- `insert(pos, "text")` → Insert at position.
    

```cpp
string s = "helloworld";
s.insert(5, " ");  // s becomes "hello world"
```

---

### ✅ 7️⃣. `append()` or `+` operator

```cpp
string s1 = "Hello";
string s2 = "World";

string s3 = s1 + " " + s2;  // "Hello World"
s1.append(" World");       // "Hello World"
```

---

### ✅ Summary Table

|Function|Example|Purpose|
|---|---|---|
|`stringstream ss(s)`|See example above|Split a string easily into parts|
|`find(sub)`|`s.find("abc")`|Find position of substring|
|`substr(pos, len)`|`s.substr(2, 4)`|Extract part of string|
|`length()` or `size()`|`s.length()`|Get string size|
|`stoi()`|`stoi("123")` → 123|String → Integer|
|`to_string()`|`to_string(456)` → "456"|Integer → String|
|`erase(pos, len)`|`s.erase(3, 2)`|Remove part of string|
|`insert(pos, "str")`|`s.insert(1, "X")`|Insert at position|
|`+` or `append()`|`s1 + s2`, `s1.append(s2)`|Concatenate strings|
