## 🧠 What Are Props?

**Props** (short for **properties**) are how you **pass data** from one component to another in **React**.

### 🔁 Think of props like function arguments.

Just like this:

```js
function greet(name) {
  return "Hello " + name;
}

greet("Alice"); // "Hello Alice"
```

In React:

```jsx
function Welcome(props) {
  return <h1>Hello {props.name}</h1>;
}

// Usage
<Welcome name="Alice" />
```

➡️ `props.name` is `"Alice"`  
➡️ The component renders: `<h1>Hello Alice</h1>`

---

## 🔧 How Props Work in React

### 1. **Define a component**

```jsx
function Greeting(props) {
  return <p>Hi {props.name}!</p>;
}
```

### 2. **Use it somewhere and pass props**

```jsx
<Greeting name="John" />
```

### 3. **What React sees**

You're calling `Greeting({ name: "John" })`, just like a function!

---

## 🧒 Special Prop: `children`

As mentioned before, `children` is a **special prop** that represents whatever is inside your component tags.

Example:

```jsx
function Card(props) {
  return <div className="card">{props.children}</div>;
}

// Usage
<Card>
  <h2>Hello</h2>
  <p>This is inside the card.</p>
</Card>
```

➡️ `props.children` contains:

```jsx
<>
  <h2>Hello</h2>
  <p>This is inside the card.</p>
</>
```

## 🎨 Visual Analogy

Think of a **component** as a **cookie cutter**, and **props** as the **dough you're giving it**. You can reuse the cutter (component), but change the flavor (props).

```jsx
<Button text="Submit" />
<Button text="Cancel" />
```

You’re using the same `<Button>` component but passing in different data each time via `props`.

## ✅ Summary

|Concept|Meaning|
|---|---|
|Props|Data passed into a React component (like function arguments)|
|Usage|`<ComponentName propName="value" />`|
|Access|Inside component: `props.propName`|
|`children`|Special prop for anything between component tags|
