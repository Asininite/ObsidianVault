## INNER JOIN
- records with matches in both tables
  you'll only get rows where left table and right table match

## OUTER JOIN
- records where there is a match in either table
- if right table has no match, you'll have data from left table and blanks in right table

## LEFT/RIGHT JOIN
- all records from left table and matches from right
- **always have data from left table** and if there is a **match**, data from right table
- vice versa for RIGHT JOIN
