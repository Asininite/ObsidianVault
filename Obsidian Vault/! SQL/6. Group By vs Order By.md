## Group BY
- putting your data into buckets
- used with **aggregate functions** like SUM AVG COUNT
	  to calculate total salary
	  average salary
	  count of employees in each department
	  
```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department;
```

## ORDER BY
- sorting rows in a particular order
- sorting the entire table based on one or more columns 

```sql
SELECT * FROM employees
ORDER BY salary DESC;
```
