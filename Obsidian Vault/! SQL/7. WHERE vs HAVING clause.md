## WHERE
- think of it like the watchman at a gate
- use to filter individual rows based on conditions like age or name

// find students who are 18 or older
```sql
SELECT Name, Age FROM Student
WHERE Age >= 18;
```


## HAVING 
- filtering after grouping
- use when you want to filter groups created by **group by** clause based on **aggregate results** like **Counts** or **Sums** 

![[Pasted image 20250910221308.png]]
```sql
SELECT Age, COUNT(Roll_No) AS No_of_Students
FROM Student 
GROUP BY Age
HAVING COUNT(Roll_no) > 1;
```
