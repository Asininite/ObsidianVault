1. COUNT() : counts number of rows or non-null values in a column
   `COUNT(*)` gives you total number of records

2. SUM() : adds up all values in a numeric column

3. AVG() : calculates average of a numeric column
   ```sql
   AVG(Salary) 
   ```

4.  MIN() : finds the minimum value in a numeric column
   ```sql
   MIN(Salary)
   ```

5. MAX() : finds max value in a numeric column
   ```sql
 MAX(Salary)  
   ```
