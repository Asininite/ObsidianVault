- Triggers are automatic actions that allows you to set up an automatic action
### WHEN DO THEY RUN
![[Pasted image 20250910223328.png]]


```sql
CREATE TRIGGER UpdateBookStock
AFTER INSERT ON BorrowedBooks
FOR EACH ROW
BEGIN
	UPDATE Books
	SET available_count = available_count - 1
	WHERE book_id = NEW.book_id;
END;
```
