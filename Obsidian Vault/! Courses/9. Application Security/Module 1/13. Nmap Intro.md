# Nmap (Network Mapper) Overview

## 1. What is Nmap?

- **Definition:** Nmap ("Network Mapper") is an open-source network scanning and security auditing tool.
    
- **Origin:** Developed by Gordon Lyon (pseudonym: ‘Fyodor’) and first released in September 1997.
    
- **Primary Capabilities:**
    
    - Detects and fingerprints network devices, services, and operating systems.
        
    - Identifies open ports and security vulnerabilities.
        
    - Maps the structure of a computer network.
        
- **Ethical Warning:** Nmap is a powerful tool. It should **always** be used responsibly, and you must have explicit permission before scanning any target network.
    

## 2. Who Uses Nmap?

Nmap is used across the cybersecurity and IT ecosystem, including:

- **Network/System Admins:** Mapping assets, monitoring health, and troubleshooting connectivity.
    
- **Security Professionals/Pen-Testers:** Assessing security posture, identifying attack vectors, and simulating real-world attacks.
    
- **Consultants/Audit Professionals:** Verifying security standards and mitigating risks.
    
- **Researchers/Educators:** Gathering data for security studies and teaching vulnerability analysis.
    
- **Enthusiasts:** Gaining hands-on experience in networking and security.
    

## 3. Nmap Scan Types Cheat Sheet

|   |   |   |
|---|---|---|
|**Scan Type**|**Command Example**|**Description**|
|**TCP Connect**|`nmap -sT target`|Opens a full TCP connection (default scan).|
|**SYN Stealth**|`nmap -sS target`|"Half-open" scan; sends SYN packets, avoids full connection.|
|**UDP Scan**|`nmap -sU target`|Identifies open UDP services.|
|**ACK Scan**|`nmap -sA target`|Used to determine firewall configurations.|
|**Version Detection**|`nmap -sV target`|Identifies the version of services running on ports.|
|**OS Detection**|`nmap -O target`|Attempts to identify the target's operating system.|
|**Script Scanning**|`nmap -sC target`|Executes predefined scripts for extra info.|
|**Ping Scan**|`nmap -PE target`|Uses ICMP Echo Request to check availability.|
|**Traceroute**|`nmap --traceroute target`|Maps the path packets take to the target.|
|**TCP Null Scan**|`nmap -sN target`|Packets with no flags set.|
|**TCP FIN Scan**|`nmap -sF target`|Packets with FIN flag set.|
|**TCP Xmas Scan**|`nmap -sX target`|Packets with multiple TCP flags set.|

## 4. Competitive Alternatives

- **Zmap:** Optimized for fast, large-scale, internet-wide network surveys.
    
- **Masscan:** Extremely high-speed scanner capable of scanning the entire IPv4 range in minutes.
    
- **OpenVAS:** A comprehensive vulnerability scanner that provides detailed security audit reports.
    
- **Zenmap:** The official Graphical User Interface (GUI) for Nmap.
    
- **Wireshark:** A network protocol analyzer often used for network discovery and deep packet inspection.
