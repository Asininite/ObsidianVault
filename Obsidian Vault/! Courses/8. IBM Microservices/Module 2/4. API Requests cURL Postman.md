# Making API Requests: cURL and Postman

## 1. Introduction to API Requests

To interact with a REST API, you need a tool capable of transferring data to and from a server over specific network protocols (like HTTP). Developers typically use two primary categories of tools for this: **Command-Line Interface (CLI) tools** (like cURL) and **Graphical User Interface (GUI) platforms** (like Postman).

## 2. cURL (Client URL)

### A. What is cURL?

- **Definition:** Created in 1998, cURL (short for "Client URL") is a highly versatile command-line tool used to transfer data across a wide variety of network protocols.
    
- **Environments:** Because it operates in the terminal, it can be run manually at the command line or embedded directly into automated bash scripts.
    
- **Supported Protocols:** HTTP, HTTPS, FTP, IMAP, and many more.
    

### B. Common Use Cases

- Downloading files directly from the internet.
    
- Endpoint testing (checking if an API is alive and returning the right data).
    
- Debugging network issues.
    
- Error logging.
    

### C. Anatomy of a cURL Command

cURL uses "options" or "flags" (starting with one or two dashes) to modify how the request is sent. Single-dash options can often be chained together.

**Example Breakdown:**

If you want to fetch a list of products from an API in JSON format, the command might look like this:

`curl -X GET "https://api.example.com/products" -H "Accept: application/json"`

- **`curl`:** Invokes the tool.
    
- **`-x` or `-X` (Method):** Explicitly specifies the HTTP function (method) you want to use. In this case, `GET` (retrieve data). _Note: `GET` is the default if this flag is omitted._
    
- **URL:** The specific endpoint you are evaluating or calling.
    
- **`-H` (Headers):** Allows you to define HTTP headers. In this example, it tells the web server that we specifically want to work with and receive the response in JSON format.
    
- **Output:** The terminal will print out the raw JSON response returned by the microservice.
    

## 3. Postman

### A. What is Postman?

- **Definition:** Postman is a comprehensive API platform and visual GUI tool designed for building, testing, sharing, and documenting APIs.
    
- **Accessibility:** It provides an extremely user-friendly interface that abstracts away the complex command-line syntax required by tools like cURL. It is available as a downloaded desktop app or entirely online via a web browser.
    

### B. Key Features & Benefits

- **Lifecycle Orchestration:** Simplifies every step of API development. You can orchestrate multiple requests, perform repetitions/iterations, and streamline collaboration across development teams.
    
- **Protocol Support:** Fully supports standard HTTP requests (GET, POST, PUT, PATCH, DELETE).
    
- **Code Generation:** _Deep Dive feature:_ Once you build a successful API request in the Postman UI, you can click a button to instantly convert that request into usable code for languages like JavaScript, Python, C#, or Java.
    
- **Workspace Saving:** You can save your URLs, headers, and authorization tokens in "Collections" within your workspace. This means you don't have to retype complex requests every time you want to test an API.
    

### C. Real-World Example: WhatsApp Business API

The transcript highlights the WhatsApp Business Platform Cloud API to demonstrate Postman's power.

- **The Old Way:** Developers used to require significant manual setup to figure out the required headers, tokens, and payloads to send a WhatsApp message via API.
    
- **The Postman Way:** WhatsApp created a pre-filled Postman Collection. Developers simply import it, and the automation reduces onboarding time to mere minutes, allowing them to instantly start testing phone numbers and building message calls.
    

### D. The Basic Postman Workflow

1. Open a new tab in the workspace.
    
2. Select the Request Type from the dropdown (e.g., `GET`).
    
3. Paste the URL where the microservice is hosted into the address bar.
    
4. Click the **Send** button.
    
5. Analyze the neatly formatted output (JSON, HTML, etc.) in the response pane below.
    
6. Save the request to your workspace for future use.
    

## Quick Revision Questions & Answers

**1. What does the acronym cURL stand for?**

- **Answer:** Client URL.
    

**2. In a cURL command, what does the `-H` flag represent?**

- **Answer:** It stands for Headers. It allows you to pass specific HTTP headers to the server, such as telling it you want to send or receive data in JSON format.
    

**3. If you want to automate an API test to run every night on a Linux server without human intervention, which tool is better suited: cURL or Postman?**

- **Answer:** cURL. Because it is a command-line tool, it can easily be embedded into automated bash scripts that run in the background. _(Note: Postman has a CLI tool called Newman for this, but natively, cURL is the standard for raw scripting)._
    

**4. What is a major advantage Postman offers for developers who need to integrate an API into an application they are coding?**

- **Answer:** Postman can automatically convert a successful visual API request into raw, copy-pasteable code for languages like Python, JavaScript, and Java.
    

**5. Name the four standard HTTP methods supported by these tools for interacting with REST APIs.**

- **Answer:** GET, POST, PUT, and PATCH (and DELETE).
