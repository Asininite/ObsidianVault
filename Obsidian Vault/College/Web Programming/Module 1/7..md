## 1. Introduction to JavaScript — purpose and role

JavaScript is a client-side, high-level scripting language designed to add interactivity and dynamic behavior to web pages. It runs inside the browser (or on server via Node.js) and manipulates HTML/CSS at runtime. Typical uses: form validation, DOM manipulation, event handling, AJAX requests, and single-page application logic.

---

## 2. Embedding JavaScript in HTML

Three ways to include JS:

1. **Inline script** (not recommended for maintainability)
    

```html
<script>
  alert('Hello');
</script>
```

2. **External file** (recommended)
    

```html
<script src="script.js" defer></script>
```

Use `defer` or place script before `</body>` to avoid blocking DOM parsing. `async` loads asynchronously but executes immediately when loaded (useful for independent scripts).

3. **Inline event handlers** (avoid; use addEventListener)
    

```html
<button onclick="sayHi()">Click</button>
```

## 3. Basic syntax and data types

### 3.1 Data types

- **Primitive:** `undefined`, `null`, `boolean`, `number`, `string`, `bigint`, `symbol`
    
- **Object:** arrays, functions, objects, Date, RegExp, etc.
    

### 3.2 Variables

- `let` (block-scoped), `const` (block-scoped, constant reference), `var` (function-scoped, legacy).  
    Prefer `let`/`const`.
    

### 3.3 Operators & control flow

- Arithmetic: `+ - * / %`
    
- Comparison: `==` (loose), `===` (strict), `!=`, `!==`
    
- Logical: `&&`, `||`, `!`
    
- Conditional: `if/else`, `switch`
    
- Loops: `for`, `while`, `do...while`, `for...of`, `for...in`
    

### 3.4 Functions

- Function declaration:
    

```js
function add(a,b) { return a + b; }
```

- Function expression / arrow functions:
    

```js
const add = (a,b) => a + b;
```

- Callback functions: functions passed as arguments (used in event handlers and async operations).

## 4. Arrays and common methods

Create:

```js
let a = [1,2,3];
let b = new Array(1,2,3);
```

Common methods:

- `push()`, `pop()`, `shift()`, `unshift()` — modify ends
    
- `slice(start, end)` — returns subarray (non-destructive)
    
- `splice(index, deleteCount, ...items)` — modify array
    
- `join(separator)` — returns string
    
- `map()`, `filter()`, `reduce()` — functional transforms
    

Remember differences: `slice` vs `splice` (common PYQ).

## 5. Objects and JSON

Objects are key–value stores:

```js
let obj = { name: "Alice", age: 22 };
```

JSON (JavaScript Object Notation) is a text format for data interchange:

- `JSON.stringify(obj)` → string
    
- `JSON.parse(str)` → object
    

JSON data types: string, number, object, array, boolean, null. (Often tested in Module V as well.)

## 6. DOM (Document Object Model) — conceptual model

The DOM is a tree representation of the HTML document. JavaScript can traverse and modify the DOM to change content, structure, and styles.

Important interfaces/methods:

### 6.1 Selecting elements

- `document.getElementById('id')`
    
- `document.getElementsByClassName('cls')` (live HTMLCollection)
    
- `document.getElementsByTagName('tag')`
    
- `document.querySelector(selector)` (first match)
    
- `document.querySelectorAll(selector)` (static NodeList)
    

Prefer `querySelector`/`querySelectorAll` for CSS-style selectors.

### 6.2 Manipulating content

- `element.textContent` — text only
    
- `element.innerText` — human-readable text (subject to rendering)
    
- `element.innerHTML` — sets/gets HTML content (be careful with XSS)
    
- `element.value` — input value
    

### 6.3 Attributes & styles

- `element.getAttribute('src')`, `element.setAttribute('src', '...')`
    
- `element.classList.add('cls')`, `.remove()`, `.toggle()`, `.contains()`
    
- `element.style.property = 'value'` — inline styles
    

### 6.4 Creating & removing nodes

```js
let p = document.createElement('p');
p.textContent = 'Hello';
parent.appendChild(p);
parent.removeChild(child);
```

## 7. Event handling (very important for exams)

Events are user or browser actions (click, load, input, submit).

Best practice:

```js
element.addEventListener('click', handler);
```

Event object `e` has properties:

- `e.target` — originating element
    
- `e.currentTarget` — the element bound to handler
    
- `e.preventDefault()` — prevent default action (e.g., form submit)
    
- `e.stopPropagation()` — stop event bubbling
    

Examples:

- Form submission validation uses `submit` event and `e.preventDefault()`.
    
- `DOMContentLoaded` event fires when HTML parsed (useful when not using `defer`).
    

---

## 8. Form validation (client-side) — typical exam material

Client-side validation improves user experience but must be complemented by server-side validation.

Example:

```js
const form = document.querySelector('#regForm');
form.addEventListener('submit', function(e) {
  const email = document.querySelector('#email').value;
  if (!/^\S+@\S+\.\S+$/.test(email)) {
    e.preventDefault();
    alert('Invalid email');
  }
});
```

HTML5 validation attributes (`required`, `pattern`, `min`, `max`) are native and can be checked via `checkValidity()`.

## 9. DOM Traversal vs DOM Manipulation examples

Traversal:

let ul = document.querySelector('ul');

Manipulation:

```js
let li = document.createElement('li');
li.textContent = 'New item';
ul.appendChild(li);
```

## 10. AJAX and Fetch API (brief, for 10/14 marks)

AJAX allows asynchronous HTTP requests. Modern Fetch API:

```js
fetch('/api/data')
  .then(res => {
    if (!res.ok) throw new Error(res.status);
    return res.json();
  })
  .then(data => console.log(data))
  .catch(err => console.error(err));
```

Use `async/await`:

```js
async function getData() {
  const res = await fetch('/api/data');
  const data = await res.json();
  return data;
}
```

Explain `Content-Type` and JSON usage in request/response.

## 11. Important differences & pitfalls (memorise)

- `==` vs `===`: `==` does type coercion; `===` is strict equality.
    
- `let` vs `var`: scope differences cause bugs with closures.
    
- `this` context differs in arrow functions vs regular functions.
    
- `innerHTML` can lead to XSS if content uncontrolled.
    
- `for...in` iterates keys (useful for objects); `for...of` iterates values of iterable (arrays).

## 14. PYQ answers — exam-ready and detailed

### PYQ 1 — Read integer and display square (3 marks)

**Answer (copy-paste):**

```html
<script>
  const input = prompt('Enter an integer:');
  const n = parseInt(input, 10);
  if (!Number.isNaN(n)) {
    alert('Square is: ' + (n * n));
    console.log('Square is:', n * n);
  } else {
    alert('Invalid integer entered');
  }
</script>
```

Explanation: `prompt` returns string; use `parseInt` and `Number.isNaN` to validate.

---

### PYQ 2 — Array creation methods & `join()`/`slice()` (3–5 marks)

**Answer:**  
Three ways to create arrays:

1. **Literal notation:**
    

```js
let a = [1, 2, 3];
```

2. **Array constructor:**
    

```js
let b = new Array(1, 2, 3);
```

3. **Using `Array.from()` or spread operator:**
    

```js
let c = Array.from('abc'); // ['a','b','c']
let d = [...someIterable];
```

**`join(separator)`**: returns a string by concatenating array elements using `separator`. Example: `[1,2,3].join('-')` → `'1-2-3'`.

**`slice(start, end)`**: returns a shallow copy of a portion of the array from `start` (inclusive) to `end` (exclusive) without modifying original array. Example: `[1,2,3,4].slice(1,3)` → `[2,3]`.

### PYQ 3 — Event handlers & DOM manipulation (7 marks)

**Task:** Display initial paragraph “Welcome” and replace with bold “Hello from JavaScript” on button click.

**Answer (HTML + JS, copy-paste):**

```html
<!doctype html>
<html>
  <body>
    <p id="msg">Welcome</p>
    <button id="btn">Click</button>

    <script>
      const btn = document.getElementById('btn');
      const msg = document.getElementById('msg');

      btn.addEventListener('click', function () {
        // Replace paragraph text with bold text
        msg.innerHTML = '<strong>Hello from JavaScript</strong>';
      });
    </script>
  </body>
</html>
```

Explanation: `addEventListener` registers handler; `innerHTML` used to insert HTML `<strong>`. Use `textContent` if only text required (safer against XSS).

### PYQ 4 — Factorial using prompt (3–5 marks)

**Answer:**

```html
<script>
  function factorial(n) {
    if (n < 0) return undefined; // factorial undefined for negative
    let f = 1;
    for (let i = 2; i <= n; i++) f *= i;
    return f;
  }

  const input = prompt('Enter a non-negative integer:');
  const n = parseInt(input, 10);
  if (!Number.isNaN(n) && n >= 0) {
    alert('Factorial of ' + n + ' is ' + factorial(n));
  } else {
    alert('Invalid input');
  }
</script>
```

Explain loop logic and validation. For large `n`, mention JS number limits (optional for 14 marks).
