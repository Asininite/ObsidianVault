# PYQ 1 – FULL ANSWER

**Write down the general format of an HTTP request and an HTTP response. Explain the purpose of the headers ‘host’ and ‘last-modified’.**

---

## **1. General Format of an HTTP Request**

An HTTP request consists of four parts:

### (a) Request Line

Structure:

```
METHOD  REQUEST-URI  HTTP-VERSION
```

Example:

```
GET /index.html HTTP/1.1
```

### (b) Request Headers

Provide information about the client, resource preferences, and connection parameters.  
Example headers:

```
Host: www.example.com
User-Agent: Chrome/120.0
Accept: text/html
```

### (c) Blank Line

Separates headers from the body.

### (d) Optional Request Body

Present for POST/PUT requests.  
Example:

```
username=john&password=1234
```

---

## **2. General Format of an HTTP Response**

### (a) Status Line

Structure:

```
HTTP-VERSION  STATUS-CODE  REASON-PHRASE
```

Example:

```
HTTP/1.1 200 OK
```

### (b) Response Headers

```
Content-Type: text/html
Content-Length: 2890
Last-Modified: Tue, 05 Dec 2023 12:00:00 GMT
```

### (c) Blank Line

### (d) Response Body

Contains HTML, JSON, image, CSS, or any resource.

---

## **3. Purpose of the Header ‘Host’**

- Mandatory in HTTP/1.1.
    
- Specifies the domain name of the server being contacted.
    
- Required for **virtual hosting**, where multiple websites share a single IP address.
    
- Allows server to determine which specific site the client intends to access.
    

Example:

```
Host: www.ktu.edu.in
```

---

## **4. Purpose of the Header ‘Last-Modified’**

- Indicates when the resource was last changed.
    
- Enables **client-side caching** and **conditional GET requests**.
    
- Browser can send:
    

```
If-Modified-Since: Tue, 05 Dec 2023 12:00:00 GMT
```

- Server responds with:  
    **304 Not Modified** if resource unchanged → improves performance and reduces bandwidth.

# PYQ 2 – FULL ANSWER

**Explain HTTP and its significance. Describe the request and response phases in HTTP.**

---

## **1. HTTP – Introduction**

HTTP (HyperText Transfer Protocol) is an application-layer protocol used for communication between web browsers and web servers. It defines how clients request resources and how servers deliver responses.  
HTTP is stateless; each request is independent.

---

## **2. Significance of HTTP**

1. Foundation of all web communication.
    
2. Enables transfer of HTML, CSS, JavaScript, images, video, JSON, and other MIME types.
    
3. Simple, flexible, and extensible.
    
4. Supports caching, cookies, and sessions.
    
5. Uses TCP (port 80) or TLS-secured HTTPS (port 443).
    
6. Supports scalable architectures (REST, microservices).
    

---

## **3. Request Phase**

The client (browser) initiates communication.

### (a) Establishes TCP connection

Usually via port 80 (HTTP) or 443 (HTTPS).

### (b) Sends HTTP Request

Includes:

#### Request Line

```
GET /homepage.html HTTP/1.1
```

#### Headers

```
Host: www.example.com
User-Agent: Mozilla/5.0
Accept: text/html
```

#### Optional Body

(for POST/PUT)

### (c) Waiting State

Client waits for server’s response after sending the request.

---

## **4. Response Phase**

Server processes request and sends back:

### (a) Status Line

```
HTTP/1.1 200 OK
```

### (b) Response Headers

```
Content-Type: text/html
Content-Length: 4021
Last-Modified: Mon, 20 Nov 2023 10:00:00 GMT
```

### (c) Response Body

Contains requested resource.

### (d) Close or maintain connection

Persistent connections (HTTP/1.1) allow reuse for multiple requests.

---

## **5. Summary Diagram (include in exam)**

Client → (HTTP Request) → Server  
Server → (HTTP Response) → Client

# PYQ 3 – FULL ANSWER

**Explain MIME and its types with examples. Describe why MIME type must be included in HTTP responses.**

---

# 1. MIME – Introduction

MIME (Multipurpose Internet Mail Extensions) is a standard for describing the **type and format of data** being transmitted.  
In web communication, it is used to specify the content type of HTTP request/response bodies.

General format:

```
type/subtype
```

Examples:

- `text/html`
    
- `image/png`
    
- `application/json`
    
- `text/css`
    
- `video/mp4`
    

---

# 2. Major MIME Types with Examples

### 1. Text Types

```
text/plain
text/html
text/css
text/javascript
```

### 2. Image Types

```
image/jpeg
image/png
image/gif
image/webp
```

### 3. Application Types

```
application/json
application/pdf
application/zip
```

### 4. Audio and Video Types

```
audio/mpeg
video/mp4
video/webm
```

### 5. Multipart Types

Used in file uploads:

```
multipart/form-data
```

---

# 3. Why MIME Must Be Included in HTTP Responses

1. **Correct Rendering**  
    Browser must know how to interpret the content (HTML vs JSON vs image).
    
2. **Security**  
    Prevents MIME-type confusion attacks and improper script execution.
    
3. **Interoperability**  
    Ensures consistent behavior across all browsers and systems.
    
4. **Content Negotiation**  
    Allows client to request and server to deliver the appropriate format.
    

Example header:

```
Content-Type: application/json
```

5. **Avoiding misinterpretation**  
    Without MIME type, browser may guess incorrectly (content sniffing).
