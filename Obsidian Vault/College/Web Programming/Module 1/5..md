## 1. HTML5 document — overall structure (what to memorise & write)

A minimal, correct HTML5 document:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width,initial-scale=1">
    <title>Page Title</title>
    <meta name="description" content="Short description for SEO">
    <link rel="stylesheet" href="styles.css">
    <script defer src="script.js"></script>
  </head>
  <body>
    <!-- Page content goes here -->
  </body>
</html>
```

**Key points**

- `<!doctype html>` declares HTML5 and enables standards mode.
    
- `<html lang="...">` declares language (accessibility + SEO).
    
- `<meta charset="utf-8">` must be early in head to ensure correct character decoding.
    
- `<meta name="viewport">` is essential for responsive pages.
    
- Use `<link>` for CSS and `<script defer>` (or at end of body) for JS to avoid blocking rendering.
    
- Head contains metadata (not visible content); body contains visible content.

## 2. Semantic page-structure elements (why they matter)

HTML5 introduced semantic elements that describe content meaning and help accessibility, SEO, and maintainable markup:

- `<header>` — top section of page or section (logo, nav).
    
- `<nav>` — navigation links.
    
- `<main>` — main content (one per page).
    
- `<article>` — self-contained composition (blog post).
    
- `<section>` — thematic grouping of content.
    
- `<aside>` — tangentially related content (sidebar).
    
- `<footer>` — bottom of page/section.
    

**Use in answers:** When asked to design page structure for 10/14 marks, include these tags instead of generic `<div>`s.

## 3. Block vs Inline elements (concise, important)

- **Block-level**: `<div>`, `<p>`, `<h1>`–`<h6>`, `<ul>`, `<ol>`, `<table>` — take full width, introduce line breaks.
    
- **Inline**: `<span>`, `<a>`, `<img>`, `<strong>`, `<em>` — flow inside text without line breaks.
    

**Exam tip:** When asked to “differentiate block & inline tags” use 2–3 examples and behaviour differences.

## 7. Hyperlinks (`<a>`) — complete explanation (write exactly)

**Syntax**

```html
<a href="URL" target="_blank" rel="noopener noreferrer">Link text</a>
```

**Attributes**

- `href` — required for navigation target (`mailto:`, `tel:`, `#fragment`, absolute/relative URLs).
    
- `target` — `_self`, `_blank`, `_parent`, `_top` (specify where to open).
    
- `rel` — relationship for link; for `target="_blank"` include `rel="noopener noreferrer"` for security.
    
- `title` — tooltip text.
    

**Visited/Active/Unvisited**

- CSS pseudo-classes: `:link` (unvisited), `:visited`, `:hover`, `:active`.
    

Include these in 7-mark answers and add CSS snippet for active/hover states if asked.

## 8. Images (`<img>`) — attributes and accessibility

**Syntax**

```html
<img src="flower.jpg" alt="Red rose in bloom" width="300" height="200" loading="lazy">
```

**Attributes**

- `src` — image URL.
    
- `alt` — alternative text (required for accessibility; if image fails, alt displayed).
    
- `width` / `height` — pixel values or CSS sizes.
    
- `loading="lazy"` — deferred loading for performance.
    
- `title` — tooltip (optional).
    
- `srcset` / `sizes` — responsive images (high-yield for advanced answers).
    

**Fallback text**: If image cannot be loaded, the `alt` text will be shown — important for Dec 2023 PYQ.

## 9. Lists — unordered/ordered/definition

- **Unordered**: `<ul><li>...</li></ul>`
    
- **Ordered**: `<ol type="a" start="3">...</ol>` (type: `1`, `a`, `A`, `i`, `I`; start sets numbering)
    
- **Definition list**: `<dl><dt>term</dt><dd>definition</dd></dl>`
    

For CSS questions, you might be asked to set `list-style-type` or `list-style` (see past papers).

## 10. Tables — structure & important attributes

**Structure**

```html
<table border="1">
  <caption>Company Models</caption>
  <thead>
    <tr><th>Company</th><th>Model</th></tr>
  </thead>
  <tbody>
    <tr><td>Dodge</td><td>Challenger</td></tr>
    ...
  </tbody>
</table>
```

**Important attributes and elements**

- `<th>` for header cells (semantic + default bold/center).
    
- `rowspan` and `colspan` to merge cells (useful in PYQ designing complex table).
    
- `<caption>` for table title.
    
- Use CSS for styling; avoid presentational attributes (except when exam expects simple HTML table).
    

**Example use-case**: Dec 2022 PYQ asking to design a 3×3 table or a complex table—use `<tr>`, `<td>`, `rowspan`, `colspan`.

## 11. Forms — comprehensive coverage (critical topic)

Forms are heavily tested (Module 1 PYQs). Structure and attributes are key.

**Basic form**

```html
<form action="submit.php" method="post" enctype="multipart/form-data">
  <label for="name">Name</label>
  <input type="text" id="name" name="name" maxlength="25" required>
  ...
  <input type="submit" value="Submit">
</form>
```

**Important attributes**

- `action` — URL to process form.
    
- `method` — `get` or `post`.
    
- `enctype` — `multipart/form-data` for file uploads; `application/x-www-form-urlencoded` default for POST.
    
- `name` — required to submit the field value to server.
    
- `id` — useful for `label` binding.
    

**Common input types (HTML5)**

- `text`, `password`, `email`, `url`, `tel`, `number`, `range`, `date`, `time`, `datetime-local`, `month`, `week`
    
- `checkbox`, `radio`
    
- `file` (requires enctype multipart)
    
- `submit`, `reset`, `button`
    
- `hidden`
    

**Advanced input elements**

- `<textarea name="message" rows="4" cols="40"></textarea>`
    
- `<select name="experience" size="1"> <option value="0-1">0-1</option> ... </select>`
    
- `<datalist id="cities"><option value="Kochi"></datalist>` paired with `<input list="cities">`
    
- `autocomplete` attribute for inputs or form (e.g., `autocomplete="on"`, `autocomplete="email"`)
    

**Validation attributes**

- `required`, `pattern="regex"`, `min`, `max`, `step`, `maxlength`, `minlength`
    

**Accessibility**

- Use `<label for="id">` to bind labels.
    
- Include `aria-` attributes as needed for advanced answers.
    

**Example (jobsite registration — May 2023 PYQ)**: include name, address (`textarea`), email (`type="email"`), contact (`type="tel"`), DOB (`type="date"`), radio for sex, checkboxes for interests, select for experience, submit & reset.

### PYQ B — Explain tags `<textarea>`, `<span>`, `<tr>`, `<form>`, `<a>` (Dec 2022 Q11b) — (10 marks: ~2 marks each)

**Answer (write as short paragraphs, 2 lines each):**

- `<textarea>`: A multi-line text input control used in forms. Example:
    
    ```html
    <textarea name="comments" rows="4" cols="50"></textarea>
    ```
    
    `rows` and `cols` specify size.
    
- `<span>`: An inline container used to apply styles or identify portions of text without changing document flow. Example:
    
    ```html
    <p>This is a <span class="highlight">highlighted</span> word.</p>
    ```
    
- `<tr>`: Table row element used inside `<table>` within `<thead>`, `<tbody>`, or `<tfoot>`. Example:
    
    ```html
    <tr><td>Cell1</td><td>Cell2</td></tr>
    ```
    
- `<form>`: Container for input controls that collects user data and submits to server. Example:
    
    ```html
    <form action="submit.php" method="post"> ... </form>
    ```
    
- `<a>`: Anchor element for hyperlinks. Example:
    
    ```html
    <a href="https://www.example.com" target="_blank" rel="noopener">Visit</a>
    ```
    
    Use `href` for URL; `target` for where to open.
    

(Each item: give function + short example).
