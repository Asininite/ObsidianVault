## 1. What is CSS and why it matters (short statement to use in answers)

CSS (Cascading Style Sheets) is a style-sheet language used to describe presentation (layout, colors, fonts, spacing) of HTML documents. It separates content (HTML) from presentation (CSS), improving maintainability, reusability and accessibility.

---

## 2. How CSS is applied (three levels) — memorise & write

1. **Inline styles** — inside element: `<p style="color:red">` (highest specificity; poor practice).
    
2. **Internal / Embedded stylesheet** — inside `<style>` in `<head>`.
    
3. **External stylesheet** — separate `.css` file linked with `<link rel="stylesheet" href="styles.css">` (recommended).
    

Exam tip: when asked “order of precedence” list these and mention user agent and `!important`. Example short answer for 3–5 marks.

## 3. Selectors and specificity (detailed)

### 3.1 Basic selector types

- **Type selector**: `p`, `h1` — selects elements by tag.
    
- **Class selector**: `.card` — selects elements with `class="card"`.
    
- **ID selector**: `#header` — selects element with `id="header"`. (IDs must be unique.)
    
- **Universal selector**: `*` — matches all elements.
    
- **Attribute selector**: `input[type="text"]` — selects by attribute value.
    
- **Pseudo-classes**: `a:hover`, `input:focus` — states.
    
- **Pseudo-elements**: `p::first-line`, `::before`, `::after` — parts of elements.
    

### 3.2 Combinators

- **Descendant**: `nav a` — any `a` inside `nav`.
    
- **Child**: `ul > li` — direct children only.
    
- **Adjacent sibling**: `h1 + p` — `p` immediately after `h1`.
    
- **General sibling**: `h1 ~ p` — any `p` after `h1` on same level.
    

### 3.3 Specificity and cascade

Specificity determines which rule applies when selectors conflict.

- Inline style: specificity = 1000 (highest)
    
- ID selector: 100
    
- Class/attribute/pseudo-class: 10
    
- Type/pseudo-element: 1
    
- Universal `*`, combinators don’t add specificity.
    
- `!important` overrides normal cascade (use sparingly).
    

Write a short table in a 7-mark answer and show example where `.menu a {}` vs `#main .menu a {}` — the latter wins due to higher specificity.

## 4. The CSS Box Model (essential, exam high-yield)

Every element is a rectangular box composed of:

```
+---------------------------+
|        margin             |
|  +---------------------+  |
|  |     border          |  |
|  |  +---------------+  |  |
|  |  |   padding     |  |  |
|  |  | +-----------+ |  |  |
|  |  | |  content  | |  |  |
|  |  | +-----------+ |  |  |
|  |  +---------------+  |  |
|  +---------------------+  |
+---------------------------+
```

- **Content**: text/images.
    
- **Padding**: space between content and border.
    
- **Border**: line around padding.
    
- **Margin**: space outside border (collapsing margins for vertical margins).
    

Key properties and examples:

```css
.box {
  width: 200px;
  padding: 10px;
  border: 2px solid #333;
  margin: 20px;
  box-sizing: content-box; /* or border-box */
}
```

`box-sizing: border-box` makes width include padding & border (recommended for layout predictability).

Memorise margin collapsing, and that padding increases element’s visual size unless `border-box` is used.

## 5. Display and visibility

- `display` values:
    
    - `block` — element starts on new line and takes full width (e.g., `<div>`).
        
    - `inline` — flows in text line, width/height ignored (e.g., `<span>`).
        
    - `inline-block` — inline flow but respects width/height.
        
    - `none` — element removed from layout (not just invisible).
        
    - `flex`, `grid` — layout containers (covered below).
        
- `visibility: hidden` hides element but reserves space; `display:none` removes it.
    

Exam tip: for 7–10 marks include examples and when to use `inline-block` vs `block`.

## 6. Positioning — (very important; often a PYQ)

Five positioning schemes:

### 6.1 `position: static` (default)

Element follows normal document flow; `top/left` ignored.

### 6.2 `position: relative`

Element remains in normal flow; `top/left` offsets the element visually **without** affecting other elements’ layout. Use when you want to offset but keep original space.

Example:

```css
.relative { position: relative; top: 10px; left: 5px; }
```

### 6.3 `position: absolute`

Element is removed from normal flow and positioned relative to the nearest ancestor that is **positioned** (i.e., has `position` other than `static`). If none, it is positioned relative to the initial containing block (viewport). Affects layout flow of other elements (they behave as if abs element not there).

Example:

```css
.container { position: relative; }
.container .popup { position: absolute; top: 20px; right: 10px; }
```

### 6.4 `position: fixed`

Removed from flow and positioned relative to viewport. Stays fixed during scrolling.

Example: sticky navigation at top:

```css
header { position: fixed; top: 0; left: 0; width: 100%; }
```

### 6.5 `position: sticky`

Acts like `relative` until it crosses a threshold, then becomes `fixed`. Useful for sticky headers inside scroll container.

Example:

```css
h2 { position: sticky; top: 0; background: white; }
```

### Key differences to memorise (3–4 lines for exam)

- `relative` keeps space, `absolute`/`fixed` remove from flow.
    
- `absolute` is positioned relative to nearest positioned ancestor; `fixed` is relative to viewport.
    
- `sticky` toggles between `relative` and `fixed` depending on scroll.
    

This exact difference appears as a PYQ across KTU papers — memorise the wording and example.

## 7. Floats and clears (legacy but still tested)

- `float: left | right` removes element from normal flow and allows text to wrap around it (commonly used for images).
    
- Use `clear: left|right|both` on subsequent element to avoid wrapping.
    
- To contain floats inside a parent, use a clearfix:
    

```css
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}
```

Note: modern layouts prefer Flexbox/Grid instead of floats.

---

## 8. Z-index (stacking context)

- `z-index` controls stacking order for positioned elements (`position` other than `static`). Higher `z-index` appears above lower ones.
    
- New stacking contexts can be formed by elements with `position` and `z-index` or with `opacity` less than 1, transforms, etc.
    

Short note: only meaningful when elements overlap.

---

## 9. Flexbox (modern, concise but enough for exam)

Flexbox is for one-dimensional layout (row or column).

Container:

```css
.container {
  display: flex;
  flex-direction: row; /* row | column */
  justify-content: space-between; /* main-axis alignment */
  align-items: center; /* cross-axis alignment */
  gap: 16px; /* spacing between items */
}
```

Child properties:

- `flex: 1` (grow/shrink basis)
    
- `order` (reorder)
    
- `align-self` (override cross-axis alignment)
    

Common values for `justify-content`: `flex-start`, `center`, `space-between`, `space-around`.  
Common values for `align-items`: `flex-start`, `center`, `stretch`.

## 10. CSS Grid (brief mention for completeness)

Two-dimensional layout system (rows & columns). Example:

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-gap: 10px;
}
```

Not necessary to go deep unless asked; mention in 14-mark answers.

## 11. Units, colors, and shorthand (short reference)

- Units: `px`, `em`, `rem`, `%`, `vw`, `vh`.
    
- Prefer `rem` for scalable font sizes; `em` scales with parent.
    
- Color formats: named colors, `#hex`, `rgb()`, `rgba()`, `hsl()`.
    

Shorthand properties:

```css
margin: 10px 5px 15px 5px; /* top right bottom left */
border: 1px solid #000;
padding: 10px 20px;
```

## 12. Responsive design (media queries)

Basic media query:

```css
@media (max-width: 600px) {
  .sidebar { display: none; }
  .content { width: 100%; }
}
```

Principle: mobile-first (write base styles for mobile, then `min-width` breakpoints for larger screens).

## 13. Transitions & simple animations (short)

- `transition: property duration timing-function;` — smooth changes (hover).
    

```css
button { transition: background-color 0.3s ease; }
button:hover { background-color: #f00; }
```

- Keyframe animation:
    

```css
@keyframes slide {
  from { transform: translateX(-10px); }
  to   { transform: translateX(0); }
}
.box { animation: slide 0.5s ease-out; }
```

Useful for 10–14 mark answers to show polish.

## 14. Common exam tasks & code snippets (copy into answers)

### Set hover & active link background to yellow (Dec papers)

```css
a:hover,
a:active {
  background-color: yellow;
}
```

Remember CSS order (LVHA) when writing multiple pseudo-classes.

### Set ordered list style to lower-case alphabet

```css
ol { list-style-type: lower-alpha; } /* or lower-roman, decimal */
```

Variation exists across papers — `lower-alpha` equals `a, b, c`.

### Background image no tiling

```css
body {
  background-image: url('birds.jpg');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover; /* or contain */
}
```

`background-repeat: no-repeat` is the key.

### PYQ 1 (Dec 2022 / May 2024):

**“Write CSS style rules to implement the following in a web page: (i) Display the content of hyperlinks with yellow background colour and in italics (ii) Display the contents of unordered lists in bold and in Arial font (iii) Display a background image titled 'birds.jpg' with no tiling.”**  
Source: Dec 2022 / May 2024.

**Model answer (copy-paste):**

```css
/* i */
a {
  font-style: italic;
}
a:hover,
a:active {
  background-color: yellow;
}

/* ii */
ul {
  font-weight: bold;
  font-family: Arial, sans-serif;
}

/* iii */
body {
  background-image: url('birds.jpg');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover; /* optional: cover entire viewport */
}
```

Short explanation: use `:hover` and `:active` pseudo-classes; apply font family and weight to `ul`; use `background-repeat: no-repeat` to prevent tiling.

### PYQ 3 (Dec 2022 / May 2024):

**“Differentiate between Absolute Positioning and Relative Positioning.”**  
Source: Dec 2022 / May 2024.

**Model answer (7-mark style):**

**Relative Positioning**

- `position: relative;` keeps the element in the normal document flow.
    
- Using `top`, `left`, `right`, `bottom` offsets the element visually but **space originally allocated is preserved**.
    
- Useful for small nudges or as an anchor for absolutely positioned descendants.
    

**Absolute Positioning**

- `position: absolute;` removes the element from normal flow; other elements behave as if it is not present.
    
- Positioned relative to the nearest ancestor that is positioned (`position` ≠ `static`); if none, it is positioned relative to the initial containing block (usually the viewport).
    
- Useful for overlays, tooltips, or precise placement.
    

**Key differences (bullet points)**

- Flow: relative preserves space; absolute does not.
    
- Reference: relative uses its normal position; absolute uses the nearest positioned ancestor.
    
- Use cases: relative for offsets; absolute for independent positioning.

**“Explain different levels of CSS style sheets with suitable example.”** (order of precedence)

### PYQ 5 (May 2024):

**“Explain id selector and class selector in CSS with suitable examples.”**  
Source: May 2024.

**Model answer (3 marks):**

- **ID selector** uses `#idName` to select element with `id` attribute value; IDs must be unique on a page. Example:
    
    ```css
    #main-header { background: #333; color: #fff; }
    ```
    
    HTML: `<header id="main-header">...</header>`
    
- **Class selector** uses `.className` to select one or many elements sharing that class. Example:
    
    ```css
    .card { border: 1px solid #ddd; padding: 10px; }
    ```
    
    HTML: `<div class="card">...</div>`
    

Mention specificity (ID has higher specificity than class).
