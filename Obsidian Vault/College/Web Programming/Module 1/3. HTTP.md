# 1. Introduction to HTTP

HTTP (Hypertext Transfer Protocol) is the **application layer protocol** used for all communication between web browsers (clients) and web servers. It defines:

1. How clients request resources.
    
2. How servers respond to those requests.
    
3. How data is transmitted over the web.
    

HTTP is **stateless**, meaning each request is independent.

---

# 2. HTTP Request–Response Model

A web interaction consists of:

1. **Client → HTTP Request → Server**
    
2. **Server → HTTP Response → Client**
    

This cycle is repeated for every web resource the browser needs (HTML page, CSS file, images, scripts).

---

# 3. Structure of an HTTP Request

An HTTP request contains:

### 3.1 Request Line

Format:

```
METHOD  PATH  HTTP-VERSION
```

Example:

```
GET /index.html HTTP/1.1
```

### 3.2 Request Headers

Key–value pairs providing metadata about the request.

Examples:

- `Host: www.example.com`
    
- `User-Agent: Mozilla/5.0`
    
- `Accept-Language: en-US`
    

### 3.3 Blank Line

Indicates the end of headers.

### 3.4 Optional Message Body

Present mainly in methods like POST and PUT.

Example body:

```
username=john&password=1234
```

---

# 4. Structure of an HTTP Response

An HTTP response contains:

### 4.1 Status Line

Format:

```
HTTP-VERSION STATUS-CODE REASON-PHRASE
```

Example:

```
HTTP/1.1 200 OK
```

### 4.2 Response Headers

Provide metadata about the resource or server.

Examples:

- `Content-Type: text/html`
    
- `Content-Length: 3421`
    
- `Last-Modified: Tue, 10 Jan 2023 12:00:00 GMT`
    

### 4.3 Blank Line

### 4.4 Response Body

The actual content (HTML page, JSON, image, etc.)

---

# 5. HTTP Methods

These specify the operation the client wants to perform.

### 5.1 GET

Requests a resource.  
No request body.  
Data can appear in the URL as query parameters.

### 5.2 POST

Sends data to server for processing.  
Used for form submissions, logins.

### 5.3 PUT

Uploads/replaces a resource.

### 5.4 DELETE

Requests deletion of a resource.

### 5.5 HEAD

Same as GET but without body.  
Used for metadata checks.

### 5.6 OPTIONS

Returns supported methods for the resource.

### 5.7 PATCH

Makes partial changes to a resource.

---

# 6. HTTP Status Codes

Status codes are **three-digit numbers**.  
The first digit indicates category:

|Category|Range|Meaning|
|---|---|---|
|1xx|Informational|Request received, continuing process|
|2xx|Success|Request successfully received, understood, processed|
|3xx|Redirection|Client must take additional action|
|4xx|Client Error|Request contains errors|
|5xx|Server Error|Server failed to process request|

### 6.1 Common Status Codes

**200 OK** – Successful request  
**201 Created** – Resource created (POST/PUT)  
**301 Moved Permanently** – Permanent redirection  
**302 Found** – Temporary redirection  
**304 Not Modified** – Used for caching  
**400 Bad Request** – Invalid request  
**401 Unauthorized** – Authentication required  
**403 Forbidden** – Access not allowed  
**404 Not Found** – Resource not found  
**500 Internal Server Error** – Generic server error  
**503 Service Unavailable** – Server overloaded or down

---

# 7. HTTP Headers

Headers define additional information about requests or responses.

### 7.1 Common Request Headers

- **Host**: mandatory in HTTP/1.1; identifies server name.
    
- **User-Agent**: browser information.
    
- **Accept**: what content types the client can process.
    
- **Accept-Language**: preferred language.
    
- **Cookie**: sends stored cookies.
    

### 7.2 Common Response Headers

- **Content-Type**: MIME type of the returned resource.
    
- **Content-Length**: size of the body.
    
- **Set-Cookie**: server sends cookies to browser.
    
- **Last-Modified**: used for caching.
    
- **Cache-Control**: max-age, no-cache etc.
    
- **Location**: used with redirection codes.

# 8. Detailed Example of Request–Response Exchange

### 8.1 Browser Request

```
GET /courses/module1.html HTTP/1.1
Host: www.example.com
User-Agent: Chrome/110.0
Accept: text/html
```

### 8.2 Server Response

```
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 5231
Last-Modified: Tue, 28 Nov 2023 16:00:00 GMT

<html>
...
</html>
```
