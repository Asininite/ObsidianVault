# 1. HTML5 APIs — Introduction

HTML5 introduced a set of **browser-native APIs** that allow websites to behave like rich applications without plugins.  
They provide access to:

- Client-side storage
    
- Multimedia control
    
- Drawing and graphics
    
- Location services
    
- Offline web applications
    
- Component-based structure
    

Each API has specific methods, events, capabilities and restrictions.

# 2. Web Storage API — Local Storage & Session Storage

(Highly important: appears repeatedly in exams)

HTML5 Storage is an alternative to cookies, providing **key–value storage** in the browser.

## 2.1 Local Storage

- Persistent storage — survives page reloads and browser restarts
    
- Max capacity ~5–10 MB depending on browser
    
- Domain-specific (each domain has its own storage)
    
- Data stored as **strings**
    

### Methods

```js
localStorage.setItem("username", "Alice");
localStorage.getItem("username");     // "Alice"
localStorage.removeItem("username");
localStorage.clear();
```

### Advantages over cookies

- Larger storage
    
- Not sent with every HTTP request
    
- Pure client-side (no overhead)
    
- Secure from network sniffing unless exposed by JS
    
- No need for expiration dates
    

---

## 2.2 Session Storage

- Storage cleared when tab is closed
    
- Scope: per-tab, per-window
    
- Same API as `localStorage`  
    Used for temporary data: form state, current selections, temporary app context.
    

### Example

```js
sessionStorage.setItem("token", "abc123");
```

---

## 2.3 Difference between Local and Session Storage

|Feature|Local Storage|Session Storage|
|---|---|---|
|Lifetime|Permanent|Until tab closes|
|Storage|5–10 MB|5–10 MB|
|Scope|All tabs for same domain|Single tab|
|Use cases|Preferences, caching|Temp data|

# 3. Geolocation API

(High scoring because answer is straightforward)

Allows site to retrieve user’s geographical location **only with user permission**.

### Methods

```js
navigator.geolocation.getCurrentPosition(success, error);
```

`success` callback receives `position.coords.latitude`, `position.coords.longitude`.

### Example

```js
navigator.geolocation.getCurrentPosition(function(pos){
  console.log(pos.coords.latitude, pos.coords.longitude);
});
```

### Limitations

- Requires HTTPS
    
- Requires user consent
    
- Deliveries can be inaccurate depending on device
    
- Might be blocked by browser privacy settings

# 4. Audio and Video API (HTML5 Multimedia)

HTML5 embeds multimedia natively without plugins (Flash obsolete).

### 4.1 Audio element

```html
<audio controls>
  <source src="song.mp3" type="audio/mpeg">
</audio>
```

### 4.2 Video element

```html
<video width="640" height="360" controls>
  <source src="movie.mp4" type="video/mp4">
</video>
```

### Important Attributes

- `controls` — show play/pause
    
- `autoplay` — auto play (often blocked by browser)
    
- `loop` — repeat
    
- `muted` — start muted
    
- `poster` — placeholder image for videos

# 5. Canvas API

Canvas is a bitmap drawing surface for 2D graphics, animations, charts, games.

### Basic Usage

```html
<canvas id="c" width="400" height="300"></canvas>
```

```js
const ctx = document.getElementById('c').getContext('2d');
ctx.fillStyle = "red";
ctx.fillRect(10, 10, 150, 100); // draw rectangle
```

### Common Operations

- Shapes: `fillRect()`, `strokeRect()`, `clearRect()`
    
- Paths: `beginPath()`, `lineTo()`, `stroke()`, `arc()`
    
- Text: `fillText()`, `strokeText()`
    
- Images: `drawImage()`
    

Canvas is **pixel-based**, not object-based. Redrawing is required for animation.

# 7. JSON (JavaScript Object Notation)

(Very important — appears in almost every paper)

JSON is a text format for data interchange. Lightweight, language-independent.

### JSON Syntax

- Data is name–value pairs
    
- Data separated by commas
    
- Curly braces for objects
    
- Square brackets for arrays
    
- Values: string, number, object, array, boolean, null
    

### Example

```json
{
  "name": "Alice",
  "age": 22,
  "skills": ["HTML", "CSS", "JS"]
}
```

### JavaScript usage

```js
let obj = JSON.parse(jsonString);
let jsonStr = JSON.stringify(obj);
```

# 8. Web Components (Custom Elements, Shadow DOM, Templates)

HTML5 introduced a standard for reusable custom elements.

## 8.1 Custom Elements

```js
class MyCard extends HTMLElement {
  connectedCallback(){
    this.innerHTML = "<p>Hello</p>";
  }
}
customElements.define('my-card', MyCard);
```

Then use in HTML:

```html
<my-card></my-card>
```

## 8.2 Shadow DOM

Isolated DOM tree for styling encapsulation.

```js
this.attachShadow({mode: 'open'});
```

## 8.3 Template tag

```
<template id="tmp">
  <p>Hello</p>
</template>
```

Templates are inert fragments until cloned via JS.
