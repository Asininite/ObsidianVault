### Q1 (3 Marks): What is a URL? Give an example.

**Answer:**  
A **URL (Uniform Resource Locator)** is the address used to access a resource on the internet. It specifies the protocol to be used, the location of the server, and the path to the resource.  
For example:  
`https://www.example.com/index.html`

- `https` → protocol
    
- `www.example.com` → domain name (server)
    
- `/index.html` → path of the file

### Q2 (7 Marks): Distinguish between URI, URL, and URN with suitable examples.

**Answer:**  
A **URI (Uniform Resource Identifier)** is a string of characters that uniquely identifies a resource on the Internet. It is a broad term that includes both URLs and URNs.

1. **URL (Uniform Resource Locator):**
    
    - Identifies the location of a resource and the method to access it.
        
    - Example: `https://www.wikipedia.org/wiki/HTML`
        
2. **URN (Uniform Resource Name):**
    
    - Identifies a resource by its name without specifying its location.
        
    - Example: `urn:isbn:0451450523` (represents a book using ISBN number).
        
3. **URI (Uniform Resource Identifier):**
    
    - General concept that can be either a URL or a URN.
        
    - Example: Both `https://www.google.com` (URL) and `urn:oasis:names:specification:docbook:dtd:xml:4.1.2` (URN) are URIs.
        

**In summary**, all URLs and URNs are URIs, but not all URIs are URLs. URLs focus on _where_ and _how_ to access, URNs focus on _what_ the resource is, and URI is the umbrella term.
