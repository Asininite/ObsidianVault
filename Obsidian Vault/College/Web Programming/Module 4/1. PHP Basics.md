### Topic 1: PHP Basics (Variables, Data Types, and Strings)

This section covers the core building blocks of the PHP language. We'll discuss how PHP handles variables and data, and then look at common operations, especially for strings.

#### **Client-Side vs. Server-Side Scripting**

Before diving into PHP, it's important to understand where it fits.

- **Client-side scripting** (like JavaScript) refers to code that is executed on the user's web browser1. It's useful for making web pages interactive without needing to contact the server for every small change.
    
- **Server-side scripting** (like PHP) refers to code that is executed on the web server before the page is sent to the client's browser222. When a user requests a page containing PHP code, the server processes the PHP script, which might involve tasks like accessing a database or performing calculations3. The output of the PHP script is generated as plain HTML, which is then sent to the browser4444. The client never sees the original PHP code, only the final HTML output5.
    

PHP is considered a server-side scripting language6.

### **PHP Variables**

In PHP, variables are used to store information or data values.

**1. Syntax and Declaration**

- A variable in PHP starts with a `$` sign, followed by the name of the variable.
    
- Unlike languages such as C, you do not need to declare a variable's data type before assigning a value to it.
    

2. Dynamic Typing

PHP is considered a dynamically typed language. This means you don't have to declare the data type of a variable beforehand8. The PHP interpreter automatically determines the data type of a variable at runtime based on the value that is assigned to it9. A single variable can hold different data types at different points in the script.

_Example:_

PHP

```
$myVar = "Hello World!"; // $myVar is a string
$myVar = 100;            // Now, $myVar is an integer
$myVar = true;           // Now, $myVar is a boolean
```

3. Variable Scope and Lifetime

The scope of a variable refers to the part of the script where it can be accessed11. PHP has several variable scopes12:

- **Local Variables:** A variable declared inside a function has a local scope and can only be accessed within that function.
    
- **Global Variables:** A variable declared outside of any function has a global scope. It can be accessed from anywhere in the script _except_ from within a function. To access a global variable from inside a function, you must use the `global` keyword or the `$GLOBALS` superglobal array.
    
- **Static Variables:** Normally, when a function is completed, all of its variables are deleted. If you want a local variable to retain its value between function calls, you can declare it as `static`.
    

4. Bound vs. Unbound Variables

In PHP, a variable is considered "**bound**" if it has been **assigned** **a** **value**. If a variable has been declared but not assigned a value, or has been unset, it is "unbound." You can test whether a variable is bound (i.e., has a value and is not NULL) using the isset() function.

### **PHP Data Types**

PHP supports several data types18.

**Primitive Types:**

- **String:** A sequence of characters, like `"Hello world!"`.
    
- **Integer:** A non-decimal number, like `100` or `-50`.
    
- **Float (or Double):** A floating-point number, like `3.14`.
    
- **Boolean:** Can have two values: `true` or `false`.
    
- **NULL:** A special data type that can have only one value: `NULL`. It represents a variable with no value.
    

**Compound Types:**

- **Array:** Used to store multiple values in a single variable.
    
- **Object:** An instance of a class.
    

#### **PHP Arrays**

PHP arrays are highly flexible and differ significantly from arrays in languages like C.

**Key Differences from C Arrays:**

- **Dynamic Size:** PHP arrays can grow or shrink in size dynamically at runtime. C arrays have a fixed size determined at compile-time21.
    
- **Mixed Data Types:** A single PHP array can store values of different data types (e.g., integers, strings, objects). C arrays can only store values of a single, uniform data type.
    
- **Associative Keys:** PHP arrays are fundamentally ordered map. They map keys to values. These keys can be standard integer indices (like in C) or they can be associative string keys.
    

Ways to Create an Array in PHP:

There are several ways to declare an array:

1. **Using the `array()` construct:**
    
    PHP
    
    ```
    // Indexed array
    $my_array = array("apple", "banana", "orange"); 
    
    // Associative array
    $ages = array("Alice" => 30, "Bob" => 30, "Harry" => 35); 
    ```
    
2. **Using square bracket `[]` syntax (short array syntax):**
    
    PHP
    
    ```
    // Indexed array
    $my_array = ["apple", "banana", "orange"]; [cite: 640]
    
    // Associative array
    $ages = ["Alice" => 30, "Bob" => 30];
    ```
    

#### **PHP Array Functions**

PHP provides a rich set of functions for manipulating arrays27272727272727.

- **`count()`:** Returns the number of elements in an array28.
    
    - Example: `echo count($my_array); // Output: 3` 29
        
- **`array_search()`:** Searches an array for a given value and returns the corresponding key if successful30.
    
    - Example: `echo array_search("banana", $my_array); // Output: 1` 31
        
- **`sort()`:** Sorts an array's elements in ascending order32.
    
- **`rsort()`:** Sorts an array's elements in descending (reverse) order33.
    
- **`asort()`:** Sorts an associative array in ascending order, according to the value, while maintaining the key-value relationship343434.
    
- **`ksort()`:** Sorts an associative array in ascending order, according to the key35.
    
- **`array_slice()`:** Extracts a slice (a portion) of an array36.
    
    - Example: `print_r(array_slice($my_array, 1, 2)); // Output: Array ( [0] => banana [1] => orange )` 37

### **PHP String Processing**

PHP offers a wide variety of functions for working with strings383838.

**Common String Handling Functions:**

- **`strlen($string)`:** Returns the length of a string39.
    
    - Example: `$string = "Hello World!"; echo strlen($string); // Output: 12` 40
        
- **`strpos($haystack, $needle)`:** Finds the position of the first occurrence of a substring (`$needle`) in a string (`$haystack`)41. Returns `false` if not found42.
    
    - Example: `$string = "Hello World!"; echo strpos($string, "World"); // Output: 6` 43
        
- **`str_replace($search, $replace, $subject)`:** Replaces all occurrences of the search string with the replacement string44.
    
    - Example: `$new_string = str_replace("World", "PHP", $string); echo $new_string; // Output: "Hello PHP!"` 45
        
- **`substr($string, $start, $length)`:** Returns a part of a string46. You specify the starting position and optional length47.
    
    - Example: `$string = "Hello World!"; echo substr($string, 0, 5); // Output: "Hello"` 48
        
- **`strtolower($string)`:** Converts a string to lowercase49.
    
    - Example: `echo strtolower("Hello World!"); // Output: "hello world!"` 50
        
- **`strtoupper($string)`:** Converts a string to uppercase51.
    
    - Example: `echo strtoupper("Hello World!"); // Output: "HELLO WORLD!"` 52
        

#### **`implode()` vs. `explode()`**

This is a common exam topic used for converting between strings and arrays53535353.

- **`implode($delimiter, $array)`:** Joins the elements of an array into a single string, with each element separated by the specified delimiter54.
    
    - _Example:_
        
        PHP
        
        ```
        $array = array("apple", "banana", "orange"); [cite: 691]
        $string = implode(",", $array); [cite: 695]
        echo $string; // Output: "apple,banana,orange" [cite: 696]
        ```
        
- **`explode($delimiter, $string)`:** Splits a string into an array by a specified delimiter55.
    
    - _Example:_
        
        PHP
        
        ```
        $string = "apple,banana,orange"; [cite: 699]
        $array = explode(",", $string); [cite: 701]
        // $array is now ["apple", "banana", "orange"] [cite: 702]
        ```
        

In summary, `implode()` builds a string from an array, while `explode()` creates an array by breaking up a string56.
