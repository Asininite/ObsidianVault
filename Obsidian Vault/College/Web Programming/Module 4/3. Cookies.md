### **Answering a 3-Mark Question on Cookies**

**Question:** What are cookies in PHP and how are they used?

**Your Answer Structure:**
A cookie is a small text file that a server asks a user's web browser to store on their computer11. Its main purpose is to identify a user and maintain information about them across multiple page views, allowing the server to remember them during and between browsing sessions22.

Cookies are created in PHP using the `setcookie()` function, which must be called before any HTML is outputted.

- **To create a cookie:**
```php
    // Creates a cookie named "user" that expires in 1 hour
    setcookie("user", "John Doe", time() + 3600, "/");
    ```

Once set, the cookie's value can be accessed on subsequent page loads using the `$_COOKIE` superglobal array.

- **To access the cookie:**
```php
    if (isset($_COOKIE["user"])) {
        echo "Welcome back, " . $_COOKIE["user"];
    }
    ```

### **Answering a 7-Mark Question on Cookies**

A 7-mark question requires a comprehensive explanation, covering the "what," "why," "how," and potential issues. Let's use a typical PYQ as our guide.

**Question:** What are the uses of cookies in web pages? Describe the syntax for setting cookies in PHP. How can you access and delete the cookie using the `setcookie()` function? 5555

**Your Answer Structure:**

#### **Part 1: Definition and Uses of Cookies**

A cookie is a piece of information stored by a server in a text file on a client's computer6. It is a small file that the server embeds on the user's machine7. Each time the same computer requests a page from the server, the browser sends the cookie along with the request8. This mechanism allows a website to maintain information about a client during and between browsing sessions, effectively "remembering" the user9.

The primary uses of cookies in web pages are:

- **Storing User Preferences:** Websites can use cookies to remember user-specific information, such as their zip code to provide a local weather report, or a preferred language setting10101010.
    
- **Session Management (Keeping a User Logged In):** Cookies can store a user's login credentials or a unique identifier, so the user does not have to log in on every single page they visit on a site11.
    
- **Tracking User Behavior:** Cookies can be used to track user activity, such as which pages they visit on a site. This information is valuable for marketers to determine the effectiveness of advertising campaigns or for website owners to analyze site popularity12121212.
    

It is important to note that sensitive information like credit card numbers should not be stored in cookies, as they are typically stored as plain text and can be read by other programs on the user's computer13.

#### **Part 2: Syntax for Setting (Creating) Cookies in PHP**

In PHP, cookies are created with the `setcookie()` function14.

**Crucial Rule:** The `setcookie()` function sends information as part of the HTTP headers. Therefore, it **must be called before any HTML or other output** is sent to the browser15151515.

The general syntax for the function is:

```php
setcookie(name, value, expire, path, domain, secure, httponly);
```

The most important parameters are:

- `name`: (Required) The name of the cookie17.
    
- `value`: The data to be stored in the cookie.
    
- `expire`: An optional Unix timestamp representing the cookie's expiration date18. A common practice is to use the `time()` function plus a number of seconds. For example, `time() + (86400 * 30)` sets the cookie to expire in 30 days.
    
    - If the `expire` parameter is not set, the cookie is a **session cookie**, which lasts only until the user closes their browser.
        
    - If `expire` is set, it is a **persistent cookie**.
        
- `path`: An optional parameter that specifies the server path where the cookie will be available. Setting it to `"/"` makes the cookie available across the entire website.

**Example of setting a persistent cookie:**

```php
<?php
// Set a cookie named 'username' with the value 'Alex' that expires in one day.
setcookie("username", "Alex", time() + 86400, "/");
?>
<html>
<body>
    <p>Cookie has been set.</p>
</body>
</html>
```

#### **Part 3: Accessing and Deleting Cookies in PHP**

Accessing Cookies:

When a browser sends a request to a server, it includes any relevant cookies. PHP automatically populates this data into the `$_COOKIE` superglobal array. This is an associative array where the keys are the cookie names.

To access a cookie, you use its name as the key for the `$_COOKIE` array. It is best practice to first check if the cookie is set using the `isset()` function to avoid errors24242424.

**Example of accessing a cookie:**

PHP

```
<?php
if (isset($_COOKIE["username"])) {
    echo "Welcome back, " . $_COOKIE["username"] . "!";
} else {
    echo "Welcome, guest!";
}
?>
```

Deleting Cookies:

To delete a cookie, you must use the setcookie() function again. The correct and most reliable method is to set the cookie's expiration time to a date in the past252525252525252525. This signals the browser to remove the cookie.

**Example of deleting a cookie:**

PHP

```
<?php
// Set the expiration date to one hour ago
setcookie("username", "", time() - 3600);
?>
<html>
<body>
    <p>Cookie 'username' has been deleted.</p>
</body>
</html>
```

When deleting, it is important to use the same path and domain parameters that were used when the cookie was originally set to ensure it is properly removed26262626.
```php
setcookie("nameofcookie", "value", time() + 86400, "/")
```
