**1. What is an Iterative Statement? (The Introduction)** An iterative statement is a control structure that causes a statement or a collection of statements to be executed zero, one, or more times. It is commonly referred to as a "loop".

The primary categories of iteration control statements are defined by how language designers answer two basic questions:

1. How is the iteration controlled?
    
2. Where should the control mechanism appear in the loop statement (e.g., at the top or the bottom)?
    

**2. Category 1: Counter-Controlled Loops** A counter-controlled loop is structured around counting the number of times the loop executes.

- **Mechanism:** It has a specific variable, called the **loop variable**, in which the current count value is maintained.
    
- **Loop Parameters:** It requires three means of specification (called loop parameters):
    
    1. The initial value of the loop variable.
        
    2. The terminal (ending) value of the loop variable.
        
    3. The stepsize, which is the difference between sequential values of the loop variable.
        
- **Example:** The standard `for` loop in C or Java (e.g., `for (int i = 0; i < 10; i++)`).
    

**3. Category 2: Logically Controlled Loops** A logically controlled loop does not strictly count; instead, it relies on a condition being true or false.

- **Mechanism:** The repetition control is based entirely on a **Boolean expression** rather than a counter.
    
- **Pretest vs. Posttest:** * _Pretest:_ The test for loop completion occurs _before_ the loop body is executed (e.g., a standard `while` loop). If the condition is false initially, the loop never runs.
    
    - _Posttest:_ The test for loop completion occurs _after_ the loop body is executed (e.g., a `do-while` loop). This guarantees that the loop body will always be executed at least once.

## The 6-Mark Comparison (PYQ)

If you are explicitly asked to _"Differentiate counter-controlled and logically controlled iteration statements"_, draw a table or use bullet points contrasting these key areas:

- **Basis of Control:** * _Counter:_ Controlled by a dedicated loop variable and strict loop parameters (initial, terminal, stepsize).
    
    - _Logical:_ Controlled by the evaluation of a Boolean expression.
        
- **Determinism (Number of iterations):**
    
    - _Counter:_ The number of iterations is usually known or can be calculated before the loop begins executing.
        
    - _Logical:_ The number of iterations is generally unknown beforehand, as it depends on dynamic changes to variables within the loop body that affect the Boolean expression.
        
- **Complexity:**
    
    - _Counter:_ Generally more complex to design because it requires managing scope, type, and evaluation of the loop variable and its parameters.
        
    - _Logical:_ Simpler in design, focusing purely on whether a single condition evaluates to true or false.
