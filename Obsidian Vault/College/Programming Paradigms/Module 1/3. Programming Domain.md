This is a highly factual topic that frequently appears in exams when asking about the domains of computer applications and their associated languages.

Because computers are used in a myriad of different areas—from controlling nuclear power plants to running mobile games—programming languages have been developed with very different goals to suit these specific areas.

Here is the verbose breakdown of the five major programming domains you need to know:

### **1. Scientific Applications**

- **Origin:** The first digital computers in the late 1940s and early 1950s were invented specifically for scientific applications.
    
- **Characteristics:** These applications typically use relatively simple data structures, such as arrays and matrices. However, they require massive numbers of floating-point arithmetic computations. Their most common control structures are counting loops and selections.
    
- **Associated Languages:** Fortran was the very first language developed specifically for scientific applications. ALGOL 60 was also intended to be used in this domain.
    

### **2. Business Applications**

- **Origin:** The use of computers for business began in the 1950s.
    
- **Characteristics:** Business languages are uniquely characterized by their facilities for producing elaborate reports. They require precise ways to describe and store decimal numbers and character data, as well as the ability to specify exact decimal arithmetic operations (for dealing with currency and finance).
    
- **Associated Languages:** The first successful high-level language for business was COBOL, which appeared in 1960. It remains the most commonly used language for these specific types of applications even today.
    

### **3. Artificial Intelligence (AI)**

- **Characteristics:** AI is a broad area of computer applications characterized by the use of _symbolic_ rather than _numeric_ computations. Because of this symbolic nature, the computation is much more conveniently done using linked lists of data rather than the standard arrays used in scientific computing.
    
- **Associated Languages:** The first widely used programming language developed for AI was the functional language LISP, appearing in 1959. This was followed by Prolog in the early 1970s. More recently, AI applications are also being written in systems languages like C.
    

### **4. Systems Programming**

- **Characteristics:** This domain involves writing the systems software for a machine, which collectively includes the operating system and the programming support tools. Code in this domain needs to be highly efficient and interact closely with the hardware.
    
- **Associated Languages:** In the 1960s and 1970s, computer manufacturers created special machine-oriented high-level languages for their specific hardware (e.g., IBM used PL/S, Digital used BLISS, and Burroughs used Extended ALGOL). Today, most systems software is written in more general programming languages, primarily C and C++. A prime example is the UNIX operating system, which is written almost entirely in C.
    

### **5. Web Software**

- **Characteristics:** The World Wide Web is supported by an extremely eclectic (diverse) collection of languages. Because there is a pervasive need for dynamic Web content, computation capabilities are often directly embedded into the technology used for content presentation (like embedding code into an HTML document).
    
- **Associated Languages:** This domain spans from pure markup languages like HTML (which strictly speaking is not a programming language) to general-purpose programming languages like Java. The dynamic functionality is most often provided by scripting languages, such as JavaScript or PHP.
    

For an exam answer, ensuring you list both the **characteristics** (what the domain needs to do) and the **associated languages** (the tools built to do it) will secure full marks for this topic.
