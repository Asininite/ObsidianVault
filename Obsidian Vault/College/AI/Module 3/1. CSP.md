- A problem that is solved when each variable has a value that satisfies all constraints on the variable
- It is defined by three components : 
	  1.  X : set of variables 
	  2. D : set of domains
	  3. C : set of constraints that specify allowable combinations of values
- eg : Map coloring problem 
	  X : regions on map
	  D : set of different colors
	  C : no two adjacent regions can have same color

## What is backtracking search wrt CSP? 
- Backtracking search is a depth-first search algorithm commonly used for solving CSPs. It incrementally builds a potential solution by assigning values to variables one by one. If an assignment violates a constraint, or if an unassigned variable has no valid values left, the algorithm **backtracks** by undoing the previous assignment and trying a different value. This systematically explores the space of possible assignments while pruning branches of the search tree that violate constraints
