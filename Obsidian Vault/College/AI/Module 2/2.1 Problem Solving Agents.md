
A **problem-solving agent** is a type of goal-based agent that decides what to do by finding a **sequence of actions** that leads to a desirable state (a goal).

Imagine you're in Kochi (the initial state) and you want to get to Thiruvananthapuram (the goal state). You don't just "go"; you need to figure out a _sequence_ of actions: "Drive to Alappuzha," then "Drive to Kollam," then "Drive to Thiruvananthapuram." The "thinking" part where you figure out this sequence is called **Search**.

The agent follows a simple three-step process:

1. **Formulate:** The agent analyzes the problem and defines it in a precise, formal way. This is the most critical step.
    
2. **Search:** The agent uses a search algorithm (like BFS, DFS, A*) to find the best sequence of actions to reach the goal.
    
3. **Execute:** Once the agent finds a solution (the sequence of actions, or "path"), it performs the actions one by one.

This is the core of problem-solving. An agent can't solve a vague problem. It must first **formulate** it into a **well-defined problem**, which has five specific components.

> **⭐ Exam Focus:** This is a very common 8-mark or 10-mark question. You will be asked to list these 5 components and apply them to an example.

The 5 components are:

1. **Initial State:** The state where the agent begins.
    
2. **Actions:** A description of the possible actions available to the agent. This is often a **Successor Function**, which takes a state and returns a set of (action, new_state) pairs.
    
3. **Transition Model:** A description of what each action does. (e.g., `Result(state, action)` returns the `new_state`).
    
4. **Goal Test:** A function that determines whether a given state is a goal state.
    
5. **Path Cost:** A function that assigns a numeric cost to a path (a sequence of actions). The agent will try to find the path with the **lowest** cost.
    

These components implicitly define the **State Space** of the problem—the set of all reachable states, which can be drawn as a graph where states are nodes and actions are edges.
