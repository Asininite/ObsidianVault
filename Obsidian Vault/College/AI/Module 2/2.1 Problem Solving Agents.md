
A **problem-solving agent** is a type of goal-based agent that decides what to do by finding a **sequence of actions** that leads to a desirable state (a goal).

magine you're in Kochi (the initial state) and you want to get to Thiruvananthapuram (the goal state). You don't just "go"; you need to figure out a _sequence_ of actions: "Drive to Alappuzha," then "Drive to Kollam," then "Drive to Thiruvananthapuram." The "thinking" part where you figure out this sequence is called **Search**.


![[Pasted image 20251109165047.png]]
- **Problem - Solving agents**: These are goal-based agents using atomic representation
- **Planning agents**: Goal-based agents using more advanced or factored representation 

![[Pasted image 20251109165208.png]]
The agent follows a simple three-step process:

1. **Formulate:** The agent analyzes the problem and defines it in a precise, formal way. This is the most critical step.
    
2. **Search:** The agent uses a search algorithm (like BFS, DFS, A*) to find the best sequence of actions to reach the goal.
    
3. **Execute:** Once the agent finds a solution (the sequence of actions, or "path"), it performs the actions one by one.
