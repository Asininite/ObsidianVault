# ⭐ **Knowledge-Based Agent (Clear Explanation)**

A **Knowledge-Based Agent (KBA)** is an agent that uses **explicit knowledge** about the world and **logical reasoning** to decide what actions to take.  
Instead of reacting blindly like reflex agents, KB agents **store facts** about the environment in a **Knowledge Base (KB)** and use inference to derive new facts and decide actions.

### What your PDF says:

A knowledge-based agent has a **Knowledge-Base**, containing “sentences in a formal language.” It uses two functions:  
✔ **TELL** – add new percepts/facts to the KB  
✔ **ASK** – infer what action to take based on the KB  

Logical reasoning allows agents to work effectively even in **partially observable environments**.

# ⭐ **Simple Explanation**

A Knowledge-Based Agent works like a human who:

1. **Observes** the environment → gets percept
    
2. **Updates** its internal knowledge → stores what it just observed
    
3. **Reasons** using logic → figures out what must be true
    
4. **Decides** the best action based on what it knows
    

So the agent does **thinking** before acting.

# ⭐ **Key Components (from PDF, explained clearly)**

### 1️⃣ **Knowledge Base (KB)**

A collection of facts represented in a **formal language** (like propositional logic or FOL).  

### 2️⃣ **Inference Engine**

Uses logic to derive new conclusions from the KB.  
This is what allows the agent to "reason."

### 3️⃣ **TELL operation**

Adds new information to the KB whenever the agent perceives something.  
“Tell it what it needs to know.”  

### 4️⃣ **ASK operation**

Queries the KB to choose the next action.  
“Asks what to do next.”
