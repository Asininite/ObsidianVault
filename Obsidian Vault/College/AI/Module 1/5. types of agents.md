# ✅ **1. Simple Reflex Agent**

This is the **most basic** agent type.

### **Definition**

A simple reflex agent chooses its actions **only on the basis of the current percept**, ignoring all past percepts.  
(PDF: _“Select actions on the basis of the current percept, ignoring the rest of the percept history.”_ )

### **How it works**

It uses **condition–action rules**, like:

- _If dirt present → Suck_
    
- _If tail-light red → Brake_  
    (PDF: examples given with braking. )
    

### **Limitations**

- Works **only in fully observable environments** because it doesn’t remember anything.  
    (PDF: _“This will work only if … environment is fully observable.”_ )

# ✅ **2. Model-Based Reflex Agent**

This is an **improvement** over simple reflex agents.

### **Why it is needed**

Simple reflex agents fail in **partially observable environments** because they cannot keep track of what they cannot see.  
Model-based reflex agents fix this by maintaining **internal state**.

### **Definition**

A model-based reflex agent uses:

1. **Internal state** – memory of past percepts
    
2. **A model of how the world works** (i.e., knowledge of state change rules)
    

(PDF: _“Agents have internal state… represents change in the world… requires knowledge of how the world evolves.”_ )

### **How it works**

- It updates internal state using an **UPDATE-STATE** function (PDF explicitly mentions this).
    
- Uses both **current percept + internal model** to choose an action.
    

### **Example**

A car agent tracking whether a “dangerous driver” is in front uses unseen cues and memory to maintain distance.  
(PDF figure: agent infers “dangerous driver” from internal state. )

### **Why it’s powerful**

- Works well in **partially observable** and **dynamic** environments.
    
- Maintains a belief about the world over time.

# ✅ **3. Goal-Based Agent**

This type adds **goals** on top of the internal model.

### **Definition**

A goal-based agent chooses actions by considering **future states** and selecting those that help achieve a goal.  
(PDF: _“In addition to state information, have goal information… Agents of this kind take future events into consideration.”_ )

### **Characteristics**

- Needs **search** and **planning**.
    
- Selects actions based on “Will this action eventually help me reach my goal?”
    

### **Example**

A robot planning a route to a destination.

### **Key Point**

This agent does **not** just react — it **plans**.

---

# ✅ **4. Utility-Based Agent**

Goal-based agents only distinguish **goal achieved vs goal not achieved**.  
Utility-based agents evaluate **how good** each state is.

### **Definition**

A utility-based agent uses a **utility function** to choose the action that maximizes expected utility.  
(PDF: _“Utility function… internalization of the performance measure… maximizes expected performance.”_ )

### **Why utility?**

Some goals have **tradeoffs**:

- fast vs safe
    
- cheap vs high-quality
    

Utility quantifies these preferences.

### **Example**

Self-driving car balancing:

- safety
    
- speed
    
- comfort
    
- fuel consumption

# ✅ **5. Learning Agent**

This agent can **improve itself over time**, which the PDF explains through four components.

### **Definition**

A learning agent has four parts:

1. **Learning element** – improves performance
    
2. **Performance element** – selects external actions
    
3. **Critic** – provides feedback
    
4. **Problem generator** – suggests exploratory actions  
    (PDF: detailed explanation of all four components. )
    

### **Purpose**

Learns:

- better behavior,
    
- correct models,
    
- improved strategies.
    

### **Strength**

Handles unknown or changing environments.
