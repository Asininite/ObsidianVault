**Human Agent** : 
	eyes, ears, other organs for sensors
	hands, legs vocal tract for actuator

**Robotic Agent**
	cameras, infrared range finder, NLP for sensors
	various motors for actuators

Software Agent: Software agent can have keystrokes, file contents as sensory input and
act on those inputs and display output on the screen.


term **percept** refer to the agent’s perceptual inputs at any given instant.

### Intelligent Agent
**intelligent agent** is an autonomous entity that uses sensors and actuators to act upon an environment to achieve its goals. It may also learn from its environment to better achieve those goals

## Rationality
- said to do the right thing
- has clear preference, models uncertainty, acts in a way to maximize performance measure with all possible actions
For an AI agent, the rational action is most important because in AI reinforcement learning
algorithm, for each best possible action, agent gets the positive reward and for each wrong
action, an agent gets a negative reward.

This notion of desirability is captured by a performance measure that evaluates any given
sequence of environment states.

The four fundamental rules for an AI agent are:

1. An AI agent must have the ability to perceive the environment.
2. The observations it makes must be used to make decisions.
3. These decisions should result in an action.
4. The action taken must be a rational action.

**Rationality** is a core concept for intelligent agents. A rational agent is one that performs the right actions to maximize its performance measure. The rationality of an agent is assessed based on:

- Its performance measure, which defines success.
- The agent's prior knowledge of its environment.
- The actions the agent can perform.
- The sequence of its percepts (sensory inputs).
