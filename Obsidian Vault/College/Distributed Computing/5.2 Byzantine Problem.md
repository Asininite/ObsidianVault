In this problem, a single value, which is to be agreed upon, is initialized by an arbitrary processor (called the source process). All non-faulty processors have to agree on that specific value. To solve this, the system must meet three conditions:

- **Agreement:** All non-faulty processes must agree on the same value.
    
- **Validity:** If the source process is non-faulty, then the agreed-upon value by all the non-faulty processes must be the exact same as the initial value of the source.
    
- **Termination:** Each non-faulty process must eventually decide on a value.
    

**2. Flavor 1: The Consensus Problem** The consensus problem differs because, instead of one source process giving an order, _every_ process has its own initial value.

- **Agreement:** All non-faulty processes must agree on a single, common value.
    
- **Validity:** If all the non-faulty processes happen to have the _same_ initial value, then the final agreed-upon value must be that same value.
    
- **Termination:** Each non-faulty process must eventually decide on a value.
    

**3. Flavor 2: The Interactive Consistency Problem** This differs from both previous problems. Each process has its own initial value, but instead of agreeing on one single final value, all the correct processes must agree upon a _set_ (or array) of values.

- **Condition:** There must be one agreed-upon value in the set for each process in the system.
