**Q: State the system model and assumptions made for solving agreement problems (like Byzantine Agreement) in a distributed system.**
- State the system model for the Byzantine Agreement Problem

**Answer:**

To design and prove agreement protocols, the following standard assumptions are made about the distributed system model:

1. **Synchronous System:**
    
    - The system operates synchronously. This means there is a known, strict upper bound on both the time it takes to execute a step and the time it takes for a message to travel across the network.
        
    - _Why it matters:_ Because of this, nodes can use timeouts. If a message isn't received within the time limit, the **absence of a message can be detected** and the node is assumed to be faulty.
        
2. **Reliable Communication Network:**
    
    - The communication medium is perfectly reliable.
        
    - Messages sent between non-faulty processes are delivered correctly; they are never lost, duplicated, corrupted, or altered during transit.
        
3. **Fully Connected Topology:**
    
    - Every process is directly connected to every other process in the system.
        
    - A process can send a message directly to any other process without routing it through a middleman.
        
4. **Sender Identification (Unforgeable Source):**
    
    - The receiver of a message always knows the exact identity of the sender.
        
    - A faulty process cannot "spoof" or forge the identity of a non-faulty process to trick others.
        
5. **Bounded Number of Faults:**
    
    - In a system of $n$ total processes, there is a strict assumption that at most $m$ (or $f$) processes can be faulty at any given time. (For example, in the Byzantine problem, the total number of nodes must be $n \ge 3m + 1$ to reach an agreement).
