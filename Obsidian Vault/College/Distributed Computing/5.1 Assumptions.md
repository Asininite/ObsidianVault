**Q: State the system model and assumptions made for solving agreement problems (like Byzantine Agreement) in a distributed system.**
- State the system model for the Byzantine Agreement Problem

**Answer:**

To design and prove agreement protocols, the following standard assumptions are made about the distributed system model:
### **The 7 System Assumptions for Agreement Protocols**

**1. Failure Models:** There must be a defined model of how processes fail (e.g., fail-stop, omission, or Byzantine failures). Additionally, there is an assumption about the maximum number of processes, $f$, that can be faulty at any given time out of the total $n$ processes.

**2. Synchronous vs. Asynchronous System:**

The system is assumed to be **synchronous**. This means there are known, strict upper bounds on message transmission delays and the time it takes for a processor to execute a step. (Without this, consensus is impossible if even one process crashes).

**3. Network Connectivity:**

The system assumes **full logical connectivity**. Every process has a direct point-to-point communication channel with every other process in the network.

**4. Sender Identification:**

A process that receives a message always knows the exact identity of the process that sent it. A faulty process cannot "spoof" or forge the sender's address.

**5. Channel Reliability:**

The communication channels themselves are perfectly **reliable**. Messages are never lost, duplicated, or corrupted in transit. If a failure occurs, it is assumed to be the fault of a process, not the network link.

**6. Authenticated vs. Non-Authenticated Messages:**

The system must define whether messages are **authenticated** (using unforgeable cryptographic digital signatures) or **non-authenticated** (often called "oral messages," where a traitor can alter a message before passing it on).

**7. Agreement Variable:**

The system defines the specific **agreement variable**—the data type and domain of the value that the processes are trying to agree upon. This could be a simple boolean value (0 or 1), an integer, or an array of values.
