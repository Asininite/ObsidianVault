**Q: Explain the file service architecture in detail. / Explain flat file service and directory service and their interface operations. [Part B, Q5, 6 & Model QP Q1]**

**Answer:**

An architecture that offers a clear separation of concerns for providing access to files in a distributed system is structured into three main components: a flat file service, a directory service, and a client module.

**1. The Flat File Service**

- **Responsibility:** This module is concerned solely with the implementation of operations on the actual contents of the files.
    
- **Identifiers:** It does not use standard human-readable file names. Instead, it uses Unique File Identifiers (UFIDs) to refer to files in all requests. A UFID is a long sequence of bits ensuring every file is unique across the entire distributed system.
    
- **Interface Operations:** The basic operations provided by the flat file service include:
    
    - `Read(FileId, i, n)`: Reads a sequence of up to $n$ items from a file starting at position $i$.
        
    - `Write(FileId, i, Data)`: Writes a sequence of data to a file starting at position $i$.
        
    - `Create()`: Creates a new, empty file and delivers a new UFID for it.
        
    - `Delete(FileId)`: Removes the specified file from the storage.
        
    - `GetAttributes(FileId)`: Returns the metadata/attributes for the file.
        
    - `SetAttributes(FileId, Attr)`: Updates the file's attributes.
        

**2. The Directory Service**

- **Responsibility:** This module provides the mapping between human-readable text names for files and their corresponding UFIDs. Clients can obtain the UFID of a file by giving its text name to the directory service.
    
- **Interface Operations:** The functions supported by the directory service include:
    
    - `Lookup(Dir, Name)`: Locates the text name in the directory and returns the relevant UFID.
        
    - `AddName(Dir, Name, File)`: Adds a new name mapped to a UFID into the directory.
        
    - `UnName(Dir, Name)`: Removes the entry containing the name from the directory.
        
    - `GetNames(Dir, Pattern)`: Returns all text names in the directory that match a specific regular expression pattern.
        

**3. The Client Module**

- **Responsibility:** This software runs on each individual client computer. It integrates the flat file and directory services, providing them as a single, seamless Application Programming Interface (API) to the user's application programs.
