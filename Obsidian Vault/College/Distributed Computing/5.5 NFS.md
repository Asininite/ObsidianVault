### VFS
- access transparency
- application program makes system call, determines where file lives
	  if remote, routes request to NFS client
	  if local, routes to local file system

### NFS client
- cooperates with VFS in client machine
- requests for remote files are translated into standard NFS protocol operations
- passes to server via RPC (remote procedure call)


### File Handles
- file handles are unique identifiers
	  filesystem identifier : unique num to each filesystem
	  i-node number : used to locate actual file, gets reused
	  i-node generation number : increments when i-node recycled

### Access Control and Authentication
- stateless servers
	  user identity and specific access rights checked on every request
	  integrate with Kerberos
