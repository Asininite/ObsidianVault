#### A. Information Gain (Entropy-Based)

- **Used By:** The ID3 (Iterative Dichotomiser 3) algorithm.
    
- **Concept:** It is based on the concept of **Entropy**, which measures the impurity or randomness in the data. Information Gain measures how much that entropy is _reduced_ after splitting the dataset on a specific attribute.
    
- **The Formulas:**
    
    1. Total Entropy: $Info(D) = - \sum_{i=1}^{m} p_i \log_2(p_i)$
        
    2. Attribute Entropy: $Info_A(D) = \sum_{j=1}^{v} \frac{|D_j|}{|D|} \times Info(D_j)$
        
    3. Information Gain: $Gain(A) = Info(D) - Info_A(D)$
        
- **Selection Rule:** The algorithm chooses the attribute with the **highest** Information Gain.
    

#### B. Gini Index

- **Used By:** The CART (Classification and Regression Trees) algorithm.
    
- **Concept:** It measures impurity using squared probabilities instead of logarithms, making it computationally faster. Unlike Information Gain, the Gini Index strictly enforces **binary splits** (splitting an attribute into exactly two branches).
    
- **The Formulas:**
    
    1. Gini Impurity: $Gini(D) = 1 - \sum_{i=1}^{m} p_i^2$
        
    2. Split Impurity: $Gini_A(D) = \frac{|D_1|}{|D|} Gini(D_1) + \frac{|D_2|}{|D|} Gini(D_2)$
        
- **Selection Rule:** The attribute that provides the maximum reduction in impurity (i.e., the **lowest** $Gini_A(D)$) is selected as the splitting node.
