Hyperlink - Induced Topic Search

- HITS divides the web page into two categories
	  Authorities : actual pages containing info
	  Hubs : directory pages containing links to authorities


## Algorithm
1. Collect a Base set 
	   given user query, search engine retrieves a small set of relevant pages
2. Initialize Weights 
	   each page assigned an initial Authority weight (a = 1) and Hub weight (h = 1)
3. Update Rule (Iterate) 
	   authority weight becomes sum of hug weights of all pages pointing to it
	   hug weight becomes sum of authority weights of all pages it points to
