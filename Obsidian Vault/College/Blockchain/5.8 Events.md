### **Topic 8: Events and Logs**

**The Concept (How to understand it):**

Smart contracts live in the isolated sandbox of the EVM. But what if you build a website (like a decentralized app or DApp) and you want your website to know when a transaction successfully finishes?

You use **Events**.

- **Events** are a way for your smart contract to announce to the outside world that something important just happened.
    
- When an event is "emitted" by a contract, the arguments passed to it are stored in the transaction's **Log**.
    
- **Logs** are a special data structure on the blockchain. They are _read-only_ and cannot be accessed by smart contracts themselves, which makes them **extremely cheap** to store compared to state variables.
    
- Off-chain applications (like a React.js website) can "listen" to these logs and instantly update their UI when an event is detected.
    

**The `indexed` Keyword:**

You can add the keyword `indexed` to up to three parameters in an event. This allows off-chain applications to specifically search and filter for those exact values (e.g., "Only show me `Transfer` events where _my address_ is the receiver").

### **PYQs on Topic 8**

**PYQ 1: What are Events in Solidity? Why are they used? (3 Marks)**

- **Answer:**
    
    - **Definition:** Events are interfaces with the EVM logging facilities. They allow smart contracts to emit signals to the outside world when specific actions occur.
        
    - **Usage:** They are primarily used to inform off-chain applications (like web frontends) that a transaction has been executed. They are also used as a highly gas-efficient way to store data on the blockchain, as logs cost significantly less gas than contract storage.
        

**PYQ 2: Explain how events are declared and emitted in Solidity with an example. (7 Marks)**

- **Answer:**
    
    - **Explanation (3 Marks):** Events are declared using the `event` keyword followed by the event name and the types of parameters to log. The `indexed` keyword can be applied to up to 3 parameters to make them searchable. To trigger the event inside a function, the `emit` keyword is used.
        
    - **Example (4 Marks):** _(Write this exact snippet)_
        
        Solidity
        
        ```
        pragma solidity ^0.8.0;
        
        contract Banking {
            // 1. Declare the Event
            // 'indexed' allows frontend apps to filter by the 'from' or 'to' addresses
            event Transfer(address indexed from, address indexed to, uint256 amount);
        
            function sendMoney(address _to, uint256 _amount) public {
                // ... Transfer logic goes here ...
        
                // 2. Emit the Event
                emit Transfer(msg.sender, _to, _amount);
            }
        }
        ```
