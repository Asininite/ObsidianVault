### **Topic 6: Merkle Trees**

**The Concept (How to understand it):**

In a blockchain network like Bitcoin, thousands of transactions can be packed into a single block. If a node wants to verify that one specific transaction hasn't been tampered with, does it need to download and re-hash all thousands of transactions? No. Thanks to the **Merkle Tree** (introduced by computer scientist Ralph Merkle), it only needs to check a tiny fraction of the data.

A Merkle tree is an inverted tree structure built entirely out of hashes:

- **Leaf Nodes:** The actual data blocks (transactions) are hashed. These form the bottom row.
    
- **Non-Leaf Nodes:** The hashes from the bottom row are paired up and hashed together to create the next row up.
    
- **The Merkle Root:** This pairing and hashing process continues all the way to the top until only one single hash remains. This final hash is the **Merkle Root**.
    

Because of the avalanche effect, if a hacker changes even one character in a transaction at the bottom of the tree, its hash changes. That causes its parent's hash to change, cascading all the way to the top, completely altering the Merkle Root. Therefore, the Merkle Root acts as a single, lightweight fingerprint for the entire block of data.

### **PYQs on Topic 6**

This is almost always tested as a 3-mark short-answer question. Here is exactly what the examiners are looking for.

**PYQ 1: What are Merkle trees? How can Merkle tree increase the security of blockchain? (April 2025 - 3 Marks)**

- **Answer:**
    
    - **Definition (1.5 Marks):** A Merkle tree is a hierarchical data structure where each leaf node is labeled with the cryptographic hash of a data block, and each non-leaf node is labeled with the hash of its child nodes' labels. The tree terminates at a single top hash called the Merkle Root.
        
    - **Security (1.5 Marks):** It increases security by ensuring that data blocks sent through a peer-to-peer network are whole, undamaged, and unaltered. If any single piece of data is tampered with, the cryptographic hashes all the way up to the Merkle Root will change, instantly alerting the network to the fraud.
        

**PYQ 2: What are the benefits of Merkle trees? (May 2024 - 3 Marks)**

- **Answer:**
    
    1. **Data Integrity:** They enable secure and efficient verification of large datasets to ensure data has not been altered.
        
    2. **Efficiency:** They provide a simple mathematical method for confirming facts on a network without needing to download the entire dataset.
        
    3. **Scalability:** By summarizing massive amounts of transactions into a single Merkle Root, they save massive amounts of storage space on the blockchain network.
