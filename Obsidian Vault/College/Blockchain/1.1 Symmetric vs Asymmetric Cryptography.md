### **Topic 1: Introduction to Cryptography (Symmetric vs. Asymmetric)**

**The Concept (How to understand it):** Cryptography is the science of transforming data into a secret form so that only the intended recipient can decode and understand it.

- **Encryption:** Converting the original message (Plaintext) into a coded, unreadable message (Ciphertext).
    
- **Decryption:** Restoring the plaintext from the ciphertext.
    
- **Cryptanalysis:** The process of trying to break or decipher a message without knowing the encryption details.
    

To lock and unlock these messages, we use **Keys**. Based on how these keys are used, cryptography is split into two massive categories:

**1. Symmetric Cryptography (Shared Key / Secret Key)**

- In this model, the **exact same key** is used to both encrypt and decrypt the data.
    
- Because both the sender and receiver need this key, they must safely share or agree upon it before exchanging data.
    
- There are two ways to process data symmetrically:
    
    - **Stream Ciphers:** Encrypt data one bit at a time (bit-by-bit). Examples: RC4, A5.
        
    - **Block Ciphers:** Break the plaintext into fixed-length blocks and encrypt it block-by-block. Examples: DES, AES.
        

**2. Asymmetric Cryptography (Public-Key)**

- This model uses a mathematically related **pair of keys**: a Public Key and a Private Key.
    
- The **Public Key** is placed in a public register for anyone to see and use.
    
- The **Private Key** is kept strictly secret by the owner.
    
- If someone wants to send you a secret message, they encrypt it using _your_ Public Key. Once encrypted, only _your_ Private Key can decrypt it.
