## PDCAU **Core Characteristics of Blockchain (Deep Understanding)**

Blockchain is defined by a combination of properties that work together.

### **Peer-to-Peer Network**

Nodes communicate directly with each other without a central server.  
This allows:

- Direct transfer of value
- No dependency on intermediaries

For example, sending money becomes like sending a message—direct and peer-driven.

---

### **Distributed Ledger**

Every node stores a full copy of the blockchain.

This ensures:

- Redundancy (data exists everywhere)
- Fault tolerance (system survives failures)
- Transparency (everyone sees the same data)

If one node is corrupted, others still maintain the correct version.

---

### **Cryptographic Security**

Blockchain uses cryptographic techniques to ensure:

- Data integrity (data cannot be changed unnoticed)
- Authentication (transactions are signed by users)

Each transaction is digitally signed, proving ownership and authenticity.

---

### **Append-only Structure**

Data is never deleted or overwritten. It is only added.

This means:

- Full history is preserved
- No record can be secretly modified
- Every change is traceable

---

### **Consensus-based Updates**

Since there is no central authority, the network must agree before adding data.

Consensus ensures:

- All nodes have the same version
- No invalid transaction is accepted

This is how blockchain maintains consistency across a distributed system.
