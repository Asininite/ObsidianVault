## **1. Transaction is Initiated — Creation + Digital Identity**

A transaction begins when a user (node) decides to perform some action. Most commonly, this is a **transfer of value**, like sending cryptocurrency, but it can also be:

- Executing a smart contract
- Updating some data

Now, the critical part is **digital signing**.

The user signs the transaction using their **private key**. This achieves two things:

- **Authenticity** → proves the transaction came from the real owner
- **Integrity** → ensures the data hasn’t been altered

The transaction itself is not just “send money”. It is a **structured data object** that contains:

- Sender’s address
- Receiver’s address
- Amount/value
- Rules (conditions for execution)
- Validation data (like signatures)

At this stage, the transaction exists only locally. It is **not yet trusted or accepted by the network**.

---

## **2. Transaction is Validated and Broadcast — Entering the Network**

Once created, the transaction is **broadcast to the entire network**.

This happens using protocols like **gossip protocol**, which means:

- Each node shares the transaction with its neighbors
- The transaction spreads rapidly across the network

Before forwarding it further, each node performs **basic validation checks**, such as:

- Is the digital signature valid?
- Does the sender actually have enough balance?
- Is the transaction format correct?

If it fails → discarded  
If it passes → propagated further

At this stage:

- The transaction is **known to the network**
- But it is still **not confirmed**

---

## **3. Finding a New Block — Grouping + Mining Begins**

Now comes the role of **miners (or validators)**.

These are special nodes that:

- Collect valid transactions
- Group them into a **block**

But just grouping is not enough. The block must be **accepted by the network**, and for that, it must pass the **consensus mechanism**.

In Proof of Work (PoW), this means:

- Miners compete to solve a **mathematical puzzle**
- This involves finding a value called a **nonce**
- When combined with block data, the hash must satisfy certain conditions

This is computationally intensive and creates:

- **Security** (hard to fake blocks)
- **Fair competition**

This process is called **mining**.

---

## **4. New Block is Found — Consensus Achieved**

When a miner successfully solves the puzzle:

- The block is considered **valid**
- It is said to be **“found” or “mined”**

At this moment:

- The transactions inside the block are considered **confirmed**
- The miner gets a **reward** (in cryptocurrency systems like Bitcoin)

But this is still not final until:

- The block is shared with the network
- Other nodes verify it independently

Only after verification does the network accept it.

---

## **5. Block is Added to Blockchain — Permanent Record**

Once accepted, the block is:

- Added to the blockchain
- Linked to the previous block using a **hash pointer**

This linking is crucial:

- Each block contains the **hash of the previous block**
- This creates a **chain of blocks**

Now the transaction:

- Becomes part of the permanent ledger
- Cannot be altered
- Is visible to all nodes

The updated blockchain is then:

- Broadcast to all nodes
- Each node updates its copy
