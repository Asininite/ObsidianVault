### **Topic 2: Specific CFT and BFT Algorithms**

**The Concept (How to understand it):**

Since we know networks can fail in two ways (Crash or Byzantine), engineers created specific algorithms for each scenario.

- **For Crash Faults (CFT):** We use **Paxos** or **RAFT**. These assume nodes might temporarily go offline or messages might get delayed, but no node is actively trying to hack or lie to the network.
    
- **For Byzantine Faults (BFT):** We use **PBFT**. This is a heavier, more secure algorithm that assumes some nodes are malicious traitors actively trying to forge data.

### **PYQs on Topic 2**

**PYQ 1: Explain the Paxos algorithm that solves the consensus problem with crash fault tolerance. (May 2024 - 7 Marks) / Explain how Paxos protocol can be used to achieve consensus in crash fault tolerance. (April 2025 - 7 Marks)**

- **Answer:**
    
    - **Definition (2 Marks):** Paxos is a Crash Fault Tolerant (CFT) consensus algorithm introduced by Leslie Lamport. It allows a distributed system to agree on a single value even if some nodes fail or crash, as long as a majority (quorum) of nodes are working.
        
    - **Roles (2 Marks):** Nodes in Paxos take on three primary roles (a single physical node can act as multiple roles):
        
        1. **Proposer:** Suggests a value to be agreed upon.
            
        2. **Acceptor:** Acts as the "memory." It receives proposals and votes on them.
            
        3. **Learner:** Records the final outcome once a majority of Acceptors have agreed.
            
    - **Working / The Two Phases (3 Marks):**
        
        - **Phase 1 (Prepare/Promise):** A Proposer creates a proposal with a unique ID number and sends a `Prepare` request to Acceptors. If the ID is higher than any previous request the Acceptor has seen, it sends back a `Promise` not to accept any older proposals.
            
        - **Phase 2 (Accept/Accepted):** If the Proposer receives Promises from a majority of Acceptors, it sends an `Accept` message with the value. The Acceptors accept it and forward an `Accepted` message to the Learners. Once Learners receive a majority of `Accepted` messages, consensus is reached.
            

**PYQ 2: Explain how the RAFT consensus algorithm operates to achieve agreement among peers in a blockchain. (April 2025 - 3 Marks)**

- **Answer:**
    
    - RAFT is a Crash Fault Tolerant (CFT) algorithm designed as a more understandable alternative to Paxos.
        
    - It achieves consensus by relying on **Leader Election**. In a RAFT network, nodes can be in one of three states: Leader, Follower, or Candidate.
        
    - The elected Leader handles all client requests and replicates the data (log replication) across all Follower nodes. If the Leader crashes, the Followers detect the timeout and hold a new election to choose a new Leader, ensuring the system continues to operate seamlessly.
        

**PYQ 3: Show how Practical Byzantine Fault Tolerance (PBFT) can achieve consensus in the presence of Byzantine faults. (April 2025 - 7 Marks)**

- **Answer:**
    
    - **Definition (2 Marks):** PBFT is a consensus algorithm designed to work in asynchronous systems (like the internet) and is optimized to tolerate Byzantine faults (malicious or hacked nodes intentionally sending incorrect data).
        
    - **Node Requirement (2 Marks):** To guarantee safety and liveness, PBFT requires a minimum of **$N = 3F + 1$** total nodes, where **$F$** is the number of malicious/faulty nodes.
        
    - **Working Mechanism (3 Marks):**
        
        - One node acts as the primary (Leader), and others are backups (Followers).
            
        - All nodes communicate heavily with each other, not just with the leader.
            
        - When a request comes in, nodes execute a three-phase protocol: **Pre-prepare, Prepare, and Commit**.
            
        - A node only moves to the next phase if it receives identical matching messages from a supermajority (specifically, $2F + 1$ nodes). This heavy cross-verification ensures that even if $F$ nodes are lying, the honest majority will outvote them and reach the correct consensus.
