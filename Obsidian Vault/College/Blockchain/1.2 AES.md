### **Topic 2: Advanced Encryption Standard (AES)**

**The Concept (How to understand it):**

In the previous topic, we learned that symmetric cryptography can use "Block Ciphers" to encrypt data in fixed-size chunks. **AES (Advanced Encryption Standard)** is the gold standard for block ciphers today.

Instead of scrambling the message all at once, AES puts the data through a washing machine with multiple "rounds" of scrambling.

- It takes a 128-bit block of plaintext (16 bytes) and organizes it into a **4x4 grid** called the **State Matrix**.
    
- Depending on the size of the secret key (128, 192, or 256 bits), the algorithm runs the State Matrix through 10, 12, or 14 rounds of transformations.
    
- Every single round fundamentally changes the data using four distinct mathematical steps, ensuring the final ciphertext is completely unrecognizable from the original text.

### **PYQs on Topic 2**

This is a heavy topic, and the examiners love asking about the specific transformations inside the AES rounds. Here is how to nail the 8-mark descriptive question.

**PYQ 1: What is state matrix in AES? Explain the different steps involved in conversion of initial state matrix to output state matrix. (June 2023 - 8 Marks)**

- **Answer:**
    
    - **State Matrix (2 Marks):** * The input to the AES encryption and decryption algorithms is a single 128-bit block of plaintext (16 bytes).
        
        - This block is depicted and loaded into a 4x4 square matrix of bytes.
            
        - This grid is called the **State array** (or State matrix), which is modified at each stage and round of the encryption process.
            
    - **The Conversion Steps / Transformations (6 Marks):** To convert the initial state matrix to the output state matrix, AES performs 4 distinct transformations in each round (except the final round, which skips MixColumns).
        
        1. **Substitute Bytes (SubBytes):** * A non-linear byte substitution step.
            
            - Each byte in the State matrix is independently replaced with a new byte using a fixed $16\times16$ lookup table known as an **S-box**.
                
        2. **Shift Rows:** * A transposition step where the rows of the 4x4 State matrix are cyclically shifted to the left.
            
            - The first row is not shifted, the second row is shifted by 1 byte, the third by 2 bytes, and the fourth by 3 bytes.
                
        3. **Mix Columns:** * A mathematical mixing operation that operates on the columns of the State matrix.
            
            - Each byte of a column is mapped into a new value that is a function of all four bytes in that specific column, calculated using matrix multiplication.
                
        4. **Add Round Key:** * The final step of the round where the 128 bits of the current State matrix are bitwise XORed with the 128 bits of the current round key.
