### **Topic 2: Advanced Encryption Standard (AES)**

**The Concept (How to understand it):**

In the previous topic, we learned that symmetric cryptography can use "Block Ciphers" to encrypt data in fixed-size chunks. **AES (Advanced Encryption Standard)** is the gold standard for block ciphers today.

Instead of scrambling the message all at once, AES puts the data through a washing machine with multiple "rounds" of scrambling.

- It takes a 128-bit block of plaintext (16 bytes) and organizes it into a **4x4 grid** called the **State Matrix**.
    
- Depending on the size of the secret key (128, 192, or 256 bits), the algorithm runs the State Matrix through 10, 12, or 14 rounds of transformations.
    
- Every single round fundamentally changes the data using four distinct mathematical steps, ensuring the final ciphertext is completely unrecognizable from the original text.

### **1. What is the State Matrix? (2 Marks)**

In the Advanced Encryption Standard (AES) algorithm, the input data is processed in fixed 128-bit blocks (which equals 16 bytes).

- These 16 bytes are arranged into a $4 \times 4$ square grid called the **State array** or **State matrix**.
    
- This matrix serves as the central workspace; it is loaded with the initial plaintext and is continuously modified during each encryption round until it becomes the final ciphertext.
    

---

### **2. Steps Involved in the Conversion (6 Marks)**

To convert the initial state matrix into the output state matrix for a given round, AES performs four distinct mathematical transformations.

**Step 1: Substitute Bytes (SubBytes)**

- This is a non-linear byte substitution step.
    
- Every individual byte in the state matrix is independently replaced with a new byte.
    
- This substitution is done by looking up the new value in a fixed $16 \times 16$ permutation table known as an **S-box**.
    

**Step 2: Shift Rows**

- This is a transposition (shuffling) step where the rows of the state matrix are cyclically shifted to the left.
    
- **Row 0:** Remains unchanged (shifted by 0 bytes).
    
- **Row 1:** Cyclically shifted to the left by 1 byte.
    
- **Row 2:** Cyclically shifted to the left by 2 bytes.
    
- **Row 3:** Cyclically shifted to the left by 3 bytes.
    

**Step 3: Mix Columns**

- This step operates on the matrix column by column.
    
- Each byte of a column is mapped into a completely new value that is a mathematical function of all four bytes in that specific column.
    
- This transformation is achieved through matrix multiplication against a constant matrix.
    

**Step 4: Add Round Key**

- In this final step of the round, the 128 bits of the current state matrix are bitwise **XORed** with the 128 bits of the specific round key.
    
- This step injects the actual secret key material into the data.
    

_(Note: In the very last round of AES encryption, the 'Mix Columns' step is intentionally skipped.)_
