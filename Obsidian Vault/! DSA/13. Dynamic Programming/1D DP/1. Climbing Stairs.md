Given an integer n, there is a staircase with n steps, starting from the 0th step. Determine the number of **unique ways** to reach the nth step, given that each move can be either 1 or 2 steps at a time.

Examples:

**Input**: n = 2

**Output**: 2

**Explanation**: There are 2 unique ways to climb to the 2nd step:

1) 1 step + 1 step

2) 2 steps

**Input**: n = 3

**Output**: 3

**Explanation**: There are 3 unique ways to climb to the 3rd step:

1) 1 step + 1 step + 1 step

2) 2 steps + 1 step

3) 1 step + 2 steps

## Recursion
##### **How to Identify a DP problem:**

When encountering a problem, it's crucial to recognize if it can be approached using dynamic programming (DP) techniques. This is especially relevant when the problem exhibits certain characteristics that align with the strengths of dynamic programming. Some common indicators that suggest a problem might be suitable for dynamic programming include:

1. Problem asking for count the total number of ways.
2. Given multiple ways of performing a task, it is asked which way will yield the minimum or maximum output.

If the question asks for either of the above two points mentioned earlier, recursion can be applied to attempt solving the problem. Once the recursive solution is obtained, it can be converted into a dynamic programming approach.

##### **Observation:**

The problem statement asks to count the total ways one can jump from the 0th step to the nth step by jumping either 1 or 2 steps at a time. Since the question requires counting total ways, recursion can be applied, and eventually, this problem can also be solved using dynamic programming.

##### **How to write recurrence relation:**

Once the problem has been identified, the following three steps comes handy in solving the problem:

1. Try to represent the problem in terms of indexes.
2. Try all possible choices/ways at every index according to the problem statement.
3. If the question states "count all the ways," then the sum of all choices/ways should be returned. If the question asks to find "the maximum/minimum", then the choice/way with the maximum/minimum output should be returned.

### **Solution using recursion:**

1. In recursion, top-down approach is followed, so try getting the answer that is required, then go to the base case and come back.
2. To represent the problem in terms of indices, assume n stairs as indices from 0 to N. The recursive call will basically return all the ways to reach the nth step.
  
![](https://static.takeuforward.org/premium/Dynamic%20Programming/1D%20DP/Climbing%20stairs/-0cWD5u6B)  
3. In order to consider all possible actions at an index, the choices available are either to jump 1 step or 2 steps, so proceed accordingly.
  
![](https://static.takeuforward.org/premium/Dynamic%20Programming/1D%20DP/Climbing%20stairs/-2N8YEpEh)  
4. Now, to count all the ways, return the sum of all the choices in our recursive function.
  

```java

/*It is pseudocode and not tied to 
any specific programming language.*/
f(n){
      oneStep = f(n-1)
      twoStep = f(n-2)
      return oneStep + twoStep
}
```

1. The base case would be, when the N = 0, it means, the starting and ending steps are same. So, there is just one way possible and that will be to stand there as it is.
2. Edge case: When N = 1 and f(N-2) has been called, we will reach stair -1, which is not a valid stair. Therefore, an additional edge case is added to return 1 (the only way) when N = 1.
