 The **prefix sum method** is a powerful technique used in computer science and competitive programming to **optimize the computation of the sum of elements in a subarray** (or submatrix) quickly — usually in **constant time** after some preprocessing.
 
---
### **The Basic Idea (1D Array)**

Given an array `arr[]`, and you want to **find the sum of elements from index `i` to `j`** (i.e., `arr[i] + arr[i+1] + ... + arr[j]`), you can either:
- Loop from `i` to `j` every time (O(n)), **or**
- Use **prefix sums** to do it in **O(1)** after O(n) preprocessing.
---
###  Step-by-Step
Let's say you have:
```cpp
arr = [3, 2, 5, 1, 7]
```
#### Step 1: Build the Prefix Sum Array
We define a new array `prefix[]`, where:
```cpp
prefix[i] = sum of all elements from arr[0] to arr[i]
```
So:
```
prefix[0] = 3
prefix[1] = 3 + 2 = 5
prefix[2] = 3 + 2 + 5 = 10
prefix[3] = 3 + 2 + 5 + 1 = 11
prefix[4] = 3 + 2 + 5 + 1 + 7 = 18
```
Final `prefix[]`:
```cpp
prefix = [3, 5, 10, 11, 18]
```
#### Step 2: Use it to Find Any Range Sum
To get the sum from index `i` to `j`:
```cpp
sum(i, j) = prefix[j] - prefix[i - 1]   // if i > 0
sum(0, j) = prefix[j]                   // if i == 0
```
For example:
- Sum of `arr[1]` to `arr[3]` = `2 + 5 + 1 = 8`
- Using prefix: `prefix[3] - prefix[0] = 11 - 3 = 8`
---
### Time Complexity
- Preprocessing (building prefix): O(n)
- Querying sum(i, j): O(1)
---
###  C++ Example Code
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {3, 2, 5, 1, 7};
    int n = arr.size();
    vector<int> prefix(n);

    prefix[0] = arr[0];
    for(int i = 1; i < n; i++) {
        prefix[i] = prefix[i-1] + arr[i];
    }

    int i = 1, j = 3; // sum from index 1 to 3
    int rangeSum = prefix[j] - (i > 0 ? prefix[i-1] : 0);
    cout << "Sum from index " << i << " to " << j << " = " << rangeSum << endl;

    return 0;
}
```

###  Extensions
- **2D Prefix Sums**: Used for submatrices in grids.
- **Prefix XORs / Min / Max**: Prefix technique works with other operations too (with suitable associative functions).
