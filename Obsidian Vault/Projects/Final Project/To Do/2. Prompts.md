# ✅ FULL COPILOT PROMPT LIST

**Media Verification Tool using AFSL (FF++ c23)**

## 🔹 PHASE 0 — Project skeleton & config

### Prompt 0.1 — Project structure

```
Create a clean Python project structure for a media verification tool using PyTorch.
Include folders for tools, datasets, models, attacks, losses, utils, and a main training script.
```

### Prompt 0.2 — Central configuration (IMPORTANT)

```
Create a config.py file that stores all global constants:
image size, normalization mean/std, batch size, learning rate,
PGD parameters (eps, alpha, steps), number of epochs,
and all important filesystem paths.
Ensure all modules import from this config instead of hardcoding values.
```

---

## 🔹 PHASE 1 — Data preprocessing (FF++ → faces)

### Prompt 1.1 — Frame extraction

```
Write a Python script extract_frames.py that iterates through FaceForensics++ c23 video folders,
extracts one frame every N frames using OpenCV,
and saves frames to data/frames/{video_id}/frame_XXXX.jpg.
Assume videos are organized by manipulation type.
```

---

### Prompt 1.2 — Face detection & cropping

```
Write a Python script face_preprocess.py that:
- Loads extracted frames
- Uses MTCNN to detect faces
- Crops the largest detected face
- Resizes it to the configured image size
- Saves it to data/faces/{manipulation}/{video_id}/
Skip frames where no face is detected.
```

---

### Prompt 1.3 — Build dataset catalog

```
Write a script build_catalog.py that scans the data/faces directory
and creates a catalog.csv file with columns:
path,label,video_id,manipulation.
Label should be 1 for real and 0 for fake.
video_id must represent the original source identity
and will be used later for AFSL pairing.
```

---

## 🔹 PHASE 2 — Shared preprocessing & dataset

### Prompt 2.1 — Shared preprocessing module

```
Create a preprocessing module that defines image transforms
(resize, tensor conversion, normalization)
used consistently for training, evaluation, and inference.
Ensure both Dataset and FastAPI server reuse this logic.
```

---

### Prompt 2.2 — PyTorch Dataset

```
Create a PyTorch Dataset class FFPPDataset that loads images using catalog.csv.
__getitem__ should return:
(image_tensor, label, video_id).
Use the shared preprocessing transforms.
```

---

### Prompt 2.3 — Video-wise dataset split

```
Implement train/validation/test splitting logic that operates by video_id,
ensuring no frames from the same video appear in more than one split.
```

---

## 🔹 PHASE 3 — Model definition

### Prompt 3.1 — Backbone factory

```
Write a backbone factory that loads a pretrained ResNet50 from torchvision,
removes the final classification layer,
and returns a feature extractor module.
```

---

### Prompt 3.2 — Detector model

```
Create a Detector model that wraps the backbone feature extractor
and adds a binary classification head.
The forward method must return both:
feature embeddings and classification logits.
```

---

## 🔹 PHASE 4 — Adversarial attack

### Prompt 4.1 — PGD attack

```
Implement an L-infinity Projected Gradient Descent (PGD) attack in PyTorch
for image classification.
Use parameters from config.py (epsilon, alpha, steps).
The function should return adversarial images.
```

---

## 🔹 PHASE 5 — AFSL loss (paper core)

### Prompt 5.1 — AFSL loss module

```
Write an AFSL loss module that computes:
1. Binary classification loss (BCE)
2. Adversarial similarity loss using cosine similarity
   between clean and adversarial features
3. Similarity regularization loss using cosine similarity
   between real and fake features from the same source video
Return the total loss and a dictionary of individual loss components.
```

---

### Prompt 5.2 — AFSL pairing logic

```
In the training loop, implement logic to group batch samples by video_id
and randomly pair one real and one fake sample from the same video_id
to compute the similarity regularization loss.
```

---

## 🔹 PHASE 6 — Training & checkpoints

### Prompt 6.1 — Baseline training loop

```
Write a PyTorch training loop that trains the detector model
using only binary cross-entropy loss on clean images.
Log training loss and accuracy.
Save the trained baseline model.
```

---

### Prompt 6.2 — AFSL training loop

```
Extend the training loop to:
- Generate adversarial examples using PGD
- Compute AFSL loss
- Backpropagate the total loss
- Log clean accuracy, adversarial accuracy,
  and individual AFSL loss terms
Save the AFSL-trained model.
```

that store:
model weights, backbone name, preprocessing config,
and training metadata in a single checkpoint file.
Ensure both training and inference use this utility.
