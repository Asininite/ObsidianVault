# **Topic 1: URL, URI, URN**

### Q1 (3 Marks): What is a URL? Give an example.

**Answer:**
A **URL (Uniform Resource Locator)** is the address used to access a resource on the internet. It specifies the protocol to be used, the location of the server, and the path to the resource.
For example:
`https://www.example.com/index.html`

* `https` → protocol
* `www.example.com` → domain name (server)
* `/index.html` → path of the file

---

### Q2 (7 Marks): Distinguish between URI, URL, and URN with suitable examples.

**Answer:**
A **URI (Uniform Resource Identifier)** is a string of characters that uniquely identifies a resource on the Internet. It is a broad term that includes both URLs and URNs.

1. **URL (Uniform Resource Locator):**

   * Identifies the location of a resource and the method to access it.
   * Example: `https://www.wikipedia.org/wiki/HTML`

2. **URN (Uniform Resource Name):**

   * Identifies a resource by its name without specifying its location.
   * Example: `urn:isbn:0451450523` (represents a book using ISBN number).

3. **URI (Uniform Resource Identifier):**

   * General concept that can be either a URL or a URN.
   * Example: Both `https://www.google.com` (URL) and `urn:oasis:names:specification:docbook:dtd:xml:4.1.2` (URN) are URIs.

**In summary**, all URLs and URNs are URIs, but not all URIs are URLs. URLs focus on *where* and *how* to access, URNs focus on *what* the resource is, and URI is the umbrella term.

# **Topic 2: HTTP Request and Response, GET and POST**

### Q1 (3 Marks): What is an HTTP request and response?

**Answer:**
**HTTP (Hypertext Transfer Protocol)** is the communication standard between a client (browser) and a server.

* An **HTTP Request** is sent by the client. It contains the request method (like GET or POST), the URL, headers (such as cookies, user-agent), and sometimes a body with data.
* An **HTTP Response** is sent by the server. It includes a status code (such as 200 OK or 404 Not Found), headers (such as content type), and the response body containing HTML, JSON, or other data.

---

### Q2 (7 Marks): Explain the difference between GET and POST methods in HTTP with examples.

**Answer:**
The two most common request methods in HTTP are **GET** and **POST**.

1. **GET Method**

   * Used to request data from the server.
   * Data is appended in the URL as a query string.
   * Example: `https://example.com/search?query=HTML`
   * Characteristics:

     * Parameters visible in URL (less secure).
     * Limited length of data.
     * Can be bookmarked and cached.
     * Best suited for fetching information.

2. **POST Method**

   * Used to send data to the server for processing.
   * Data is sent inside the request body.
   * Example: Submitting a login form sends data as `username=John&password=1234`.
   * Characteristics:

     * Parameters are hidden (more secure).
     * No size limitation.
     * Cannot be bookmarked.
     * Suitable for actions like registration, login, or file upload.

**Comparison in words:**
While GET requests are mainly used for retrieving information in a transparent way, POST requests are intended for sending confidential or large data securely. Both are essential for web communication, but their applications differ according to security and functionality needs.

# **Topic 3: Headings, Hyperlinks, Special Characters, Horizontal Rules**

### Q1 (3 Marks): What are headings in HTML? Give examples.

**Answer:**
Headings in HTML are defined using the tags `<h1>` to `<h6>`. They represent different levels of importance, where `<h1>` is the main heading and `<h6>` is the least significant. Headings not only provide structure and readability to a web page but also improve search engine optimization.
Example:

```html
<h1>Main Title</h1>  
<h2>Sub Title</h2>  
```

---

### Q2 (7 Marks): Explain hyperlinks, special characters, and horizontal rules in HTML with suitable examples.

**Answer:**
A **hyperlink** allows navigation between web pages. It is created using the `<a>` tag and the `href` attribute, which specifies the target URL. For example,

```html
<a href="https://www.google.com">Visit Google</a>
```

displays a clickable link “Visit Google”.

**Special characters** are represented using **HTML entities** because symbols like `<`, `>`, and `&` have reserved meanings in HTML. To display them correctly, entities are used. Examples include:

* `&lt;` for `<`
* `&gt;` for `>`
* `&amp;` for `&`
* `&nbsp;` for a non-breaking space

The **horizontal rule** is defined by the `<hr>` tag. It creates a straight line across the page to visually separate sections of content. For example,

```html
<p>Section 1</p>  
<hr>  
<p>Section 2</p>  
```

displays two paragraphs with a horizontal line between them.

Thus, hyperlinks enhance navigation, special characters ensure correct display of symbols, and horizontal rules improve the structure and readability of a web page.

### Q2 (7 Marks): Explain the structure of an HTML table with an example.


# **Topic 5: Forms and Input Types**

### Q1 (3 Marks): What is an HTML form?

**Answer:**
An **HTML form** is a section of a web page that collects user input and sends it to a server for processing. It is created using the `<form>` tag, which contains input elements such as text fields, radio buttons, checkboxes, and submit buttons. The `action` attribute specifies the URL of the server program, and the `method` attribute specifies how the data will be sent (GET or POST).
Example:

```html
<form action="submit.php" method="post">
  <input type="text" name="username">
</form>
```

---

### Q2 (7 Marks): Explain different types of input controls in HTML forms with examples.

**Answer:**
HTML forms support a wide variety of input types, each used for different purposes:

1. **Text Field (`type="text"`)** – Accepts single-line text input.
   Example: `<input type="text" name="name">`

2. **Password Field (`type="password"`)** – Hides characters as they are typed.
   Example: `<input type="password" name="pwd">`

3. **Radio Button (`type="radio"`)** – Allows the user to select *only one option* from a group.
   Example:

   ```html
   <input type="radio" name="gender" value="male"> Male  
   <input type="radio" name="gender" value="female"> Female  
   ```

4. **Checkbox (`type="checkbox"`)** – Allows the user to select *multiple options*.
   Example:

   ```html
   <input type="checkbox" name="course" value="HTML"> HTML  
   <input type="checkbox" name="course" value="CSS"> CSS  
   ```

5. **Select (Drop-down Menu)** – Created using `<select>` and `<option>`.
   Example:

   ```html
   <select name="city">
     <option>Kochi</option>
     <option>Trivandrum</option>
   </select>
   ```

6. **Textarea (`<textarea>`)** – Allows multi-line text input.
   Example: `<textarea rows="4" cols="30"></textarea>`

7. **Submit Button (`type="submit"`)** – Sends the form data to the server.
   Example: `<input type="submit" value="Submit">`

8. **Reset Button (`type="reset"`)** – Clears all fields in the form.
   Example: `<input type="reset" value="Clear">`

9. **Additional Attributes:**

   * `placeholder="Enter your name"` → Displays hint text.
   * `required` → Makes input mandatory.
   * `autofocus` → Focuses the field automatically when the page loads.
   * `datalist` → Provides a set of predefined options while typing.
     Example:

     ```html
     <input list="browsers">
     <datalist id="browsers">
       <option value="Chrome">
       <option value="Firefox">
     </datalist>
     ```

**In conclusion**, forms and input controls are essential for interaction between users and web applications. They enable tasks such as login, registration, surveys, and payment processing.

# **Topic 8: CSS Syntax, Selectors, and Types**

### Q1 (3 Marks): Write the syntax of CSS with an example.

**Answer:**
The syntax of CSS consists of a selector and a declaration block.

* **Selector** specifies which HTML element is styled.
* **Declaration block** contains one or more declarations in the form *property: value*.
  Example:

```css
h1 {
  color: blue;
  font-size: 20px;
}
```

This rule changes all `<h1>` headings to blue with a font size of 20 pixels.

---

### Q2 (7 Marks): Explain CSS selectors and types of CSS with examples.

**Answer:**
**Selectors** in CSS are patterns used to target HTML elements for styling. Common types include:

1. **Element selector:** Targets by tag name. Example: `p {color: green;}`
2. **Class selector:** Targets elements with a specific class. Example: `.highlight {background: yellow;}`
3. **ID selector:** Targets an element with a unique ID. Example: `#header {font-size: 18px;}`
4. **Group selector:** Applies the same style to multiple elements. Example: `h1, h2 {color: red;}`
5. **Pseudo-classes:** Target specific states. Example: `a:hover {color: orange;}`

**Types of CSS:**

1. **Inline CSS:** Written directly in the `style` attribute of an HTML element.
   Example: `<p style="color:blue;">Hello</p>`
2. **Internal CSS:** Written inside the `<style>` tag within the `<head>`.
   Example:

   ```html
   <style>
   body { background-color: lightgrey; }
   </style>
   ```
3. **External CSS:** Written in a separate `.css` file and linked with `<link>`.
   Example: `<link rel="stylesheet" href="style.css">`

Using CSS effectively separates content from design, improves reusability, and makes web pages easier to maintain.

# **Topic 9: CSS Order of Precedence and Conflict Resolution**

### Q1 (3 Marks): What is the order of precedence in CSS?

**Answer:**
When multiple CSS rules target the same element, the order of precedence is:

1. Inline styles (highest priority)
2. Internal styles (inside `<style>` tag)
3. External styles (linked stylesheet)
4. Browser’s default style (lowest priority)

---

### Q2 (7 Marks): Explain how conflict resolution in CSS works with an example.

**Answer:**
When multiple CSS rules apply to the same element, the browser resolves conflicts using three principles: **specificity, importance, and source order.**

1. **Specificity:** Rules with more specific selectors override general ones.
   Example:

   ```css
   p {color: blue;}  
   #intro {color: red;}
   ```

   A `<p id="intro">` will be red because an ID selector is more specific than an element selector.

2. **Importance:** A declaration marked with `!important` takes precedence over normal rules.
   Example:

   ```css
   p {color: blue !important;}  
   p {color: red;}
   ```

   The text will be blue due to `!important`.

3. **Source order:** If specificity and importance are equal, the rule written last in the stylesheet is applied.

Conflict resolution ensures that the browser can decide which rule to apply when multiple styles target the same element. This hierarchy allows developers to design complex stylesheets in a predictable way.

# **Topic 10: Absolute and Relative Positioning in CSS**

### Q1 (3 Marks): Differentiate between relative and absolute positioning in CSS.

**Answer:**

* **Relative positioning** moves an element relative to its normal position in the page. It uses properties like `top`, `left`, `right`, and `bottom`. The space originally occupied by the element is still preserved.
* **Absolute positioning** removes an element from the normal document flow and places it relative to its first positioned ancestor. Other elements behave as if it does not exist.

---

### Q2 (7 Marks): Explain absolute and relative positioning in CSS with examples.

**Answer:**
**Positioning** in CSS controls how elements are placed in relation to one another. Two important types are relative and absolute positioning.

1. **Relative Positioning:**

   * Defined using `position: relative;`
   * Moves an element from its normal flow but still occupies the original space.
   * Example:

     ```css
     p { position: relative; left: 20px; top: 10px; }
     ```

     This moves the paragraph slightly from its normal position, but the layout around it remains unchanged.

2. **Absolute Positioning:**

   * Defined using `position: absolute;`
   * The element is positioned relative to the nearest ancestor with `position: relative;`. If no such ancestor exists, it is placed relative to the document body.
   * Example:

     ```css
     div { position: relative; }  
     p { position: absolute; top: 0; left: 0; }
     ```

     Here, the paragraph is placed at the top-left corner of the containing div.

**In conclusion**, relative positioning is useful for small adjustments without disturbing layout flow, while absolute positioning is used for placing elements precisely on the page. Together, they provide powerful control over web page design.

# **Topic 11: CSS Property Values – Background, Text, Colour, Box Model**

### Q1 (3 Marks): What is the CSS box model?

**Answer:**
The **CSS box model** describes how every HTML element is treated as a rectangular box consisting of four parts:

1. **Content** – The actual text or image.
2. **Padding** – Space between content and border.
3. **Border** – Surrounds the padding and content.
4. **Margin** – Space outside the border, separating the element from others.

---

### Q2 (7 Marks): Explain CSS property values for background, text, colour, and box model with examples.

**Answer:**
CSS provides various properties to style backgrounds, text, and colours while following the box model structure.

1. **Background Properties:**

   * `background-color` sets the background colour. Example: `body {background-color: lightblue;}`
   * `background-image` sets an image as background. Example: `div {background-image: url("bg.jpg");}`
   * `background-repeat` controls repetition of the image (repeat, no-repeat, repeat-x, repeat-y).

2. **Text Properties:**

   * `font-family` specifies the typeface. Example: `p {font-family: Arial, sans-serif;}`
   * `font-size` changes text size. Example: `h1 {font-size: 24px;}`
   * `font-style` sets italics. Example: `em {font-style: italic;}`
   * `text-align` controls alignment (left, right, center, justify).
   * `text-decoration` adds effects such as underline. Example: `a {text-decoration: none;}`

3. **Colour Properties:**

   * `color` defines text colour. Example: `h2 {color: red;}`
   * Values can be given as names (`red`), hex codes (`#ff0000`), or RGB (`rgb(255,0,0)`).

4. **Box Model:**

   * Defines how content, padding, border, and margin interact.
   * Example:

     ```css
     div {
       width: 200px;
       padding: 20px;
       border: 5px solid black;
       margin: 10px;
     }
     ```

     The total width = content (200) + padding (40) + border (10) + margin (20) = 270px.

These properties allow web designers to control the appearance and layout of content precisely. Proper use of the box model ensures elements are sized and spaced consistently across a web page.

### Q1 (3 Marks): Write a JavaScript program to find the sum of two numbers.

**Answer:**

```html
<script>
  let a = 5, b = 7;
  let sum = a + b;
  document.write("Sum = " + sum);
</script>
```

This program declares two variables, adds them, and displays the result as “Sum = 12.”

---

### Q2 (7 Marks): Explain with examples any three basic JavaScript programs.

**Answer:**
JavaScript is a client-side scripting language used to make web pages interactive. Some simple programs include:

1. **Factorial of a Number:**

   ```html
   <script>
   function factorial(n) {
     let f = 1;
     for (let i = 1; i <= n; i++) {
       f *= i;
     }
     document.write("Factorial = " + f);
   }
   factorial(5);
   </script>
   ```

   Output: Factorial = 120

2. **Palindrome Check:**

   ```html
   <script>
   function isPalindrome(str) {
     let rev = str.split("").reverse().join("");
     if (str === rev)
       document.write(str + " is a palindrome");
     else
       document.write(str + " is not a palindrome");
   }
   isPalindrome("madam");
   </script>
   ```

   Output: madam is a palindrome

3. **Prime Number Check:**

   ```html
   <script>
   function isPrime(num) {
     let flag = true;
     for (let i = 2; i < num; i++) {
       if (num % i === 0) { flag = false; break; }
     }
     if (flag) document.write(num + " is prime");
     else document.write(num + " is not prime");
   }
   isPrime(7);
   </script>
   ```

   Output: 7 is prime

These programs demonstrate the use of loops, conditions, functions, and string/array methods. Such simple programs form the foundation of learning JavaScript for problem solving and form validation in web applications.

# **Topic 14: Datalist in HTML**

### Q1 (3 Marks): What is the purpose of the `<datalist>` element in HTML?

**Answer:**
The `<datalist>` element in HTML provides a list of predefined options to an input field, allowing users to either choose from the suggestions or enter their own value. It improves usability and consistency in data entry.
Example:

```html
<input list="browsers" name="browser">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
</datalist>
```

---

### Q2 (7 Marks): Explain the working of `<datalist>` with an example. How does it differ from `<select>`?

**Answer:**
The `<datalist>` element works in combination with the `<input>` element to provide a dropdown list of suggestions while still allowing free text input.

**Working:**

* An `<input>` element uses the `list` attribute to connect to a `<datalist>`.
* The `<datalist>` contains multiple `<option>` elements.
* As the user types in the input field, matching options are displayed in a dropdown list.

**Example:**

```html
<label for="city">Choose your city:</label>

  <option value="Trivandrum">
  <option value="Calicut">
</datalist>
```

* `<select>` restricts the user to choose only from the given options.
* `<datalist>` allows the user to either select a predefined option or enter custom input.

Thus, `<datalist>` provides flexibility and user-friendliness, especially for forms requiring suggestions like city names, product categories, or search terms.

# **Topic 15: JavaScript and Form Validation**

### Q1 (3 Marks): How is JavaScript used in form validation?

**Answer:**
JavaScript is used to validate form inputs before they are submitted to the server. It ensures that required fields are filled, data formats are correct, and invalid data is rejected. This reduces server load and improves user experience.
Example:

```html
<script>
function validate() {
  let name = document.getElementById("username").value;
  if (name == "") {
    alert("Name is required!");
    return false;
  }
}
</script>
```

---

### Q2 (7 Marks): Explain with examples how JavaScript can perform client-side validation of forms.

**Answer:**
JavaScript is widely used for **client-side validation** to check user inputs before sending data to the server.

1. **Checking Required Fields:**

   ```html
   if(document.getElementById("name").value == "") {
     alert("Name cannot be empty");
   }
   ```

2. **Validating Email Format:**

   ```html
   let email = document.getElementById("email").value;
   let pattern = /^[^ ]+@[^ ]+\.[a-z]{2,3}$/;
   if(!email.match(pattern)) {
     alert("Invalid email address");
   }
   ```

3. **Validating Password Length:**

   ```html
   let pwd = document.getElementById("pwd").value;
   if(pwd.length < 6) {
     alert("Password must be at least 6 characters");
   }
   ```

Form validation with JavaScript ensures accuracy and security of user input. It improves the user experience by providing instant feedback, reduces invalid submissions, and decreases unnecessary server processing.

# **Topic 16: JavaScript Basics – Variables, Data Types, and Operators**

### Q1 (3 Marks): What are variables in JavaScript?

**Answer:**
A **variable** in JavaScript is a named storage used to hold data values. Variables can be declared using `var`, `let`, or `const`.

* `var` – function scoped, older keyword.
* `let` – block scoped, recommended for general use.
* `const` – block scoped, used for constants whose values cannot be changed.
  Example:

```javascript
let age = 20;
const pi = 3.14;
```

---

### Q2 (7 Marks): Explain data types and operators in JavaScript with examples.

**Answer:**
JavaScript supports different **data types**:

1. **Primitive Data Types:**

   * String → `"Hello"`
   * Number → `25`
   * Boolean → `true` or `false`
   * Null → `null`
   * Undefined → variable declared but not assigned a value
   * Symbol (unique value introduced in ES6)
2. **Non-Primitive (Reference) Types:**

   * Objects → `{name: "John", age: 25}`
   * Arrays → `[10, 20, 30]`
   * Functions → `function add(a,b){return a+b;}`

**Operators in JavaScript:**

1. **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`
   Example: `5 + 3 = 8`
2. **Comparison Operators:** `==`, `===`, `!=`, `<`, `>`, `<=`, `>=`
   Example: `(5 == "5") is true but (5 === "5") is false`
3. **Logical Operators:** `&&` (AND), `||` (OR), `!` (NOT)
   Example: `(true && false) = false`
4. **Assignment Operators:** `=`, `+=`, `-=`
   Example: `x += 5` adds 5 to x.

Together, variables, data types, and operators form the foundation of all JavaScript programs, enabling storage, manipulation, and comparison of values.

# **Topic 17: JavaScript Control Structures**

### Q1 (3 Marks): What are control structures in JavaScript?

**Answer:**
Control structures in JavaScript determine the flow of program execution. They include:

* Conditional statements (`if`, `else if`, `else`, `switch`)
* Loops (`for`, `while`, `do...while`)
* Jump statements (`break`, `continue`)

---

### Q2 (7 Marks): Explain different control structures in JavaScript with examples.

**Answer:**

1. **Conditional Statements:**

   * `if` statement executes code if a condition is true.

     ```javascript
     if(age >= 18) { document.write("Eligible to vote"); }
     ```
   * `if...else` provides an alternative block.

     ```javascript
     if(marks >= 50) { document.write("Pass"); } else { document.write("Fail"); }
     ```
   * `switch` statement is used when multiple cases need to be tested.

     ```javascript
     switch(day) {
       case 1: document.write("Monday"); break;
       case 2: document.write("Tuesday"); break;
       default: document.write("Other day");
     }
     ```

2. **Loops:**

   * **for loop**: Runs a block of code for a fixed number of iterations.

     ```javascript
     for(let i=1;i<=5;i++){ document.write(i+" "); }
     ```
   * **while loop**: Executes as long as a condition is true.

     ```javascript
     let i=1; while(i<=5){ document.write(i+" "); i++; }
     ```
   * **do...while loop**: Executes the block at least once before checking the condition.

     ```javascript
     let i=1; do { document.write(i+" "); i++; } while(i<=5);
     ```

3. **Jump Statements:**

   * `break` → exits a loop.
   * `continue` → skips the current iteration and moves to the next.

These structures control decision-making and repetition, which are essential for solving logical problems in programming.

# **Topic 18: JavaScript Functions**

### Q1 (3 Marks): What is a function in JavaScript?

**Answer:**
A **function** in JavaScript is a block of code designed to perform a specific task. It is defined once and can be executed multiple times by calling it. Functions improve code reusability and modularity.
Example:

```javascript
function greet(name) {
  return "Hello " + name;
}
```

---

### Q2 (7 Marks): Explain different ways of defining functions in JavaScript with examples.

**Answer:**
JavaScript supports several ways to define functions:

1. **Function Declaration:**

   ```javascript
   function add(a, b) {
     return a + b;
   }
   document.write(add(5, 10));
   ```

2. **Function Expression (Anonymous Function):**

   ```javascript
   let square = function(x) { return x*x; };
   document.write(square(4));
   ```

3. **Arrow Function (ES6):**

   ```javascript
   let cube = (n) => n*n*n;
   document.write(cube(3));
   ```

4. **Immediately Invoked Function Expression (IIFE):**

   ```javascript
   (function() { document.write("Executed immediately"); })();
   ```

Functions can also take default parameters, return values, or be nested inside other functions. By modularizing tasks, functions make JavaScript programs easier to understand, maintain, and reuse.

# **Topic 19: JavaScript Arrays and Objects**

### Q1 (3 Marks): What is an array in JavaScript? Give an example.

**Answer:**
An array in JavaScript is a collection of elements stored in a single variable. It allows multiple values of the same or different data types.
Example:

```javascript
let fruits = ["Apple", "Banana", "Mango"];
document.write(fruits[0]); // Apple
```

---

### Q2 (7 Marks): Differentiate between arrays and objects in JavaScript with examples.

**Answer:**

1. **Arrays:**

   * Ordered collection of values.
   * Indexed numerically (0,1,2...).
   * Example:

     ```javascript
     let colors = ["Red", "Green", "Blue"];
     document.write(colors[1]); // Green
     ```

2. **Objects:**

   * Collection of key–value pairs.
   * Keys are strings, values can be any type.
   * Example:

     ```javascript
     let student = {name: "John", age: 21, course: "CS"};
     document.write(student.name); // John
     ```

**Comparison:**

* Arrays are best for ordered lists like numbers or names.
* Objects are used for structured data with properties.

Both arrays and objects are reference data types in JavaScript and are fundamental to building complex data structures.

# **Topic 20: JavaScript DOM (Document Object Model)**

### Q1 (3 Marks): What is the Document Object Model (DOM)?

**Answer:**
The **Document Object Model (DOM)** is a programming interface for HTML and XML documents. It represents the page as a tree structure where each element is a node. JavaScript can use the DOM to access, modify, add, or delete elements dynamically.

---

### Q2 (7 Marks): Explain DOM manipulation in JavaScript with examples.

**Answer:**
JavaScript interacts with the DOM to make web pages dynamic. Common DOM operations include:

1. **Accessing Elements:**

   * `document.getElementById("id")`
   * `document.getElementsByClassName("class")`
   * `document.querySelector("selector")`

2. **Changing Content:**

   ```javascript
   document.getElementById("demo").innerHTML = "Hello World!";
   ```

3. **Changing Style:**

   ```javascript
   document.getElementById("demo").style.color = "red";
   ```

4. **Creating and Appending Elements:**

   ```javascript
   let p = document.createElement("p");
   p.innerText = "New paragraph";
   document.body.appendChild(p);
   ```

5. **Event Handling:**

   ```javascript
   document.getElementById("btn").onclick = function() {
     alert("Button clicked!");
   };
   ```

Through DOM manipulation, developers can build interactive web pages where content updates instantly, user actions trigger events, and layouts change dynamically without reloading the page.
