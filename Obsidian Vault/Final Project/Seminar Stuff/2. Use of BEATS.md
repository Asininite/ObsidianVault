- BEATS was created to solve the problem of efficiently checking whether a document was submitted to a blockchain-based audit trail without searching the whole blockchain

BEATS’ solution:

- **Don’t search** for the data — use a **cryptographic accumulator**.
- Store a **single accumulator value** on-chain.    
- Let auditors **verify membership off-chain in constant time** (O(1)).

This solves

| Problem                    | How BEATS Fixes It                        |
| -------------------------- | ----------------------------------------- |
| Slow search                | No need to scan blockchain at all         |
| High resource usage        | Minimal RAM, CPU, and zero gas            |
| Scalability issues         | Works in constant time regardless of size |
| Complexity of verification | Simple accumulator + witness proof        |
