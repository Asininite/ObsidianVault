
## Variables

A variable is like a container that holds data that can be reused or updated later in the program. In JavaScript, variables are declared using the keywords [var](https://www.geeksforgeeks.org/javascript-var/), [let](https://www.geeksforgeeks.org/javascript-let/), or [const](https://www.geeksforgeeks.org/javascript-const/).

### ****1. var**** Keyword

The var keyword is used to declare a variable. It has a function-scoped or globally-scoped behaviour.


```
var n = 5;
var n = 20; // reassigning is allowed
```

### ****2. let Keyword****

The [let keyword](https://www.geeksforgeeks.org/javascript-let/) is introduced in ES6, has block scope and cannot be re-declared in the same scope.

let  n= 10;

n = 20; // Value can be updated

// let n = 15; //can not redeclare
### ****3. const**** Keyword

The [const keyword](https://www.geeksforgeeks.org/javascript-const/) declares variables that cannot be reassigned. It's block-scoped as well.

const n = 100;
// n = 200; This will throw an error


### Primitive Datatypes

Primitive datatypes represent single values and are immutable.

****1.**** [****Number****](https://www.geeksforgeeks.org/javascript-numbers/)****:**** Represents numeric values (integers and decimals).

let n = 42;  
let pi = 3.14;

****2.**** [****String****](https://www.geeksforgeeks.org/javascript-strings/)****:**** Represents text enclosed in single or double quotes.

let s = "Hello, World!";

****3.**** [****Boolean****](https://www.geeksforgeeks.org/javascript-boolean/)****:**** Represents a logical value (true or false).

let bool= true;

****4.**** [****Undefined****](https://www.geeksforgeeks.org/undefined-in-javascript/)****:**** A variable that has been declared but not assigned a value.

let notAssigned;

console.log(notAssigned);

  
**Output**

undefined

****5.**** [****Null****](https://www.geeksforgeeks.org/null-in-javascript/)****:**** Represents an intentional absence of any value.

let empty = null;

****6.**** [****Symbol****](https://www.geeksforgeeks.org/javascript-symbol-method/)****:**** Represents unique and immutable values, often used as object keys.

let sym = Symbol('unique');

****7.**** [****BigInt****](https://www.geeksforgeeks.org/javascript-bigint/)****:**** Represents integers larger than Number.MAX_SAFE_INTEGER.

let bigNumber = 123456789012345678901234567890n;
